# 桌巢 DeskNest

<img src="src/DeskNest.App/Assets/desknest-logo-256.png" alt="DeskNest" width="96" />

把乱桌面变成"会自己收拾、能常驻有用信息、还有点好看"的桌面。

Windows 10/11 桌面管家：**桌面整理 + 桌面组件 + 工作伙伴桌宠 + 本地 AI 出图**，四个能力在一个程序里。
GPL-3.0 开源，数据全部留在本机。

---

## 它有什么

> 下表是**产品能力全景**；✅ 已在 WinUI 主线可用，🚧 是冻结的 WPF 旧版能力、主线尚未移植。
> 当前主线的功能入口看下面「安装与运行」与 `docs/28`。

| 能力 | 说明 | 主线状态 |
| --- | --- | --- |
| **桌面收纳盒** | 盒子可拖拽缩放、卷起、自动隐藏，文件拖入即从桌面移走 | ✅ |
| **全盘搜索** | `Ctrl+F` 唤起：盒子 / 组件 / 待办 / 便签 + 全盘文件索引，索引持久化 | ✅ |
| **桌面组件** | 概览、待办（含到点提醒）、便签、文件、天气、音乐、性能，可拖动收起 | ✅ |
| **待办提醒** | 截止 / 提前量 / 重复（每天/每周/每月/农历），到点托盘气泡 + 自动生成下一轮 | ✅ |
| **托盘常驻** | 关窗隐藏到托盘、显隐桌面层 / 桌面图标、Ctrl+F 与 Alt+` 全局热键、开机自启 | ✅ |
| **盒组** | 多个盒子叠在同一位置、标签切换 | 🚧 |
| **一键整理** | 扫描 → 预览 → 执行 → 撤销；规则整理、自动整理（打开整理页时检查） | ✅ |
| **桌宠（助手型）** | 番茄钟、久坐提醒、系统状态联动、AI 问答 | 🚧 |
| **应用使用统计** | 类似 ManicTime：每个应用用了多久，默认只记进程名 | 🚧 |
| **API 面板** | 各模型余额、调用次数、成功率、平均延迟；Key 用 DPAPI 加密 | 🚧 |
| **计划关机** | 定时 / 倒计时 / 空闲触发，提前提醒、可顺延 | 🚧 |
| **AI 接口** | 只读本地接口，把盒内元数据开放给本机工具 | 🚧 |

### 永久不做

广告、推广位、桌面/资源管理器右键菜单注入、注入其它进程、静默上传数据、基础功能付费墙。

## 安装与运行（当前主线：WinUI 3 版）

> **重要**：界面已重写为 WinUI 3（`src/DeskNest.WinUI`），这是正在开发的主线。
> 它**不能像旧版那样双击 exe 运行**——WinUI 3 必须带 MSIX 包身份启动，直接跑 exe 会崩。
> 旧的 WPF 版（`src/DeskNest.App`）已冻结维护，不再是发布目标。

当前是**开发版**，安装包尚未代码签名，需要先开启 Windows 开发者模式：

1. **开启开发者模式**：设置 → 系统 → 开发者选项 → 打开「开发者模式」。
2. **打包并安装**（在项目根目录）：
   ```
   build-shell.cmd
   ```
   这个脚本会依次完成：编译 → 打成 MSIX → 注册到系统 → 启动桌巢。
   以后代码更新后重跑一次即可覆盖安装（装到固定的 `%LOCALAPPDATA%\DeskNest\AppPackage`，不会留垃圾目录）。
3. **日常启动**：从开始菜单搜索「桌巢」打开；或运行 `run-shell.cmd`（不重新编译，直接启动已安装的版本）。
4. **后台运行**：关掉主窗口 = 隐藏到系统托盘（不是退出）；点托盘图标或按 `Ctrl+F` 可唤回。
   真正退出请用托盘右键菜单的「退出桌巢」。
5. **开机自启**：主窗口 →「关于」页 →「开机自动启动」开关。

首次运行桌面上是干净的，主窗口「概览」页有「新建收纳盒」和七类桌面组件的入口，按需添加即可。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + F` | 全局唤起主窗口并打开「搜索」页（在别的程序里也有效） |
| `Alt + 反引号` | 显示 / 隐藏全部桌面盒与组件 |
| 托盘左键 / 双击 | 唤回主窗口 |
| 托盘右键 | 打开主窗口 / 搜索 / 显隐桌面层 / 显隐桌面图标 / 退出 |

> 旧版曾支持的 `Alt+Space` 快捷搜索、`Ctrl+滚轮` 调图标大小、双击桌面空白切换图标，
> 是 WPF 冻结版的功能，WinUI 主线尚未移植（前两项已被上面的新快捷键 / 托盘项替代）。

## 开发

需要 **.NET 10 SDK**（`net10.0-windows`）。版本号唯一来源在 `Directory.Build.props`（当前 2.0.0），
MSIX 的 `_msix/AppxManifest.Shell.xml` 版本号需同步。

```
build-shell.cmd     # 编译 → 打 MSIX → 注册 → 启动（主线 WinUI）
run-shell.cmd       # 只启动已注册版本，不重新编译
dotnet build DeskNest.slnx
```

核心逻辑回归用冒烟验证器（不依赖 VSTest 宿主，本机 testhost 有 Access Denied 的环境问题）：

```
dotnet run --project tools/DeskNest.Smoke -c Release
```

数据目录：`%LOCALAPPDATA%\DeskNest`（可用环境变量 `DESKNEST_DATA_DIR` 改到别处，便携模式就是把它指到程序目录）。
日志在同目录的 `winui.log` 与 `logs\desknest.log`。

### 工程结构

```
src/DeskNest.Core     逻辑与数据：模型、SQLite、文件安全操作、整理/规则引擎、搜索索引、备份……
src/DeskNest.Native   和 Windows 打交道：托盘、全局热键、桌面层/图标、拖放、Shell 图标、系统指标、DPAPI
src/DeskNest.WinUI    当前主线：主窗口 6 页、桌面盒、7 类桌面组件、托盘与提醒
src/DeskNest.App      已冻结的 WPF 旧版（只修致命 bug，不再加功能）
src/DeskNest.Module.* 可选模块（WPF 旧版在用，WinUI 主线尚未接模块系统）
tools/DeskNest.Smoke  冒烟验证器（核心逻辑断言）
docs/                 策划书、架构、测试清单；docs/28 是 WinUI 迁移的权威方案与进展
```
