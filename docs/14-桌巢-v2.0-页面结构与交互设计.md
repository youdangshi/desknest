# 桌巢 DeskNest v2.0 · 页面结构与交互设计

> 2026-10-17 · 第二步（对应流程图第 2 步「生成页面结构与交互设计」）
> 前置结论（第一步）：**v2.0 只做桌面收纳**。全盘搜索 → P1，待办/组件 → P2，整理 → P3，模块/桌宠 → P4。
> 原则：**下架不删代码**，只关入口；每个被下架的功能在附录有"怎么补回来"。

---

## 一、v2.0 范围（一句话）

> 桌面上放几个半透明盒子，文件拖进去就从桌面消失；双击盒子能打开看；删盒子时文件回到原位置。

**核心闭环 4 步**：新建盒子 → 拖文件进去 → 双击/右键打开 → 删盒子（文件还原）。

**保留**：收纳盒（普通/映射）、盒子交互、两套外观 + 卡片颜色、托盘/自启/单实例、备份与回滚、检查更新。
**下架（进计划）**：整理（分区/规则/自动）、全盘搜索、桌面组件 7 类、6 个模块、抽屉盒/待办盒/盒组、多显示器页、模块页、统计页。

## 四、盒子本身的交互（最重要的一节）

| # | 动作 | 现在的行为 | v2.0 保留？ |

| 2 | 拖四边 / 右下角 | 缩放，最小 160×96 | ✅ |
| 3 | 双击标题栏或空白 | 隐藏盒子（有「撤销」提示） | ✅ |

| 5 | 滚轮 | 改图标大小 | ✅（原来是"切组"，组已下架） |

### 4.1 盒子里的空态与加载

- **空盒**：居中一行小字"把文件拖进来，或点标题栏的 ＋"，下面一个虚线框区域。
- **拖拽悬停**：盒子边框变强调色 + 2px。
- **搬文件时**：先显示"正在移动…"再做，失败给原因（被占用/无权限），**不静默失败**。

## 六、数据模型（v2.0 最小集）

`BoxRecord` 保留：`Id / Name / Kind(Normal|Mapped) / MappedPath / ViewMode / IconSize / Opacity / Material / MaterialIntensity / CardColor / CornerRadius / LockPosition / LockSize / Width / Height / MarginX / MarginY / MonitorKey / CreatedAt / UpdatedAt`

- **新增一列** `card_color`（每盒颜色可覆盖）；老库用 `Db.EnsureColumn` 自动补。
- 下架字段（`GroupId / TitleStyle / Anchor / CollapsedX/Y / RolledUp` 等）**先留着不读**，避免老库读崩。
- `ItemRecord` 不变；`WidgetRecord / TodoRecord` 保留表结构，不加载。

## 九、验收要点（每条都要能在冒烟或手测里验）

1. 新建盒子只建空盒子，**一个文件都不动**。
2. 拖文件进盒子 → 文件真的移动进数据目录 → 盒子里出现图标 → 桌面文件消失。
3. 删盒子 → 文件逐个回原位置；原位置不存在 → 回退到桌面。
4. 改卡片颜色/材质/透明度 → 桌面盒子当场变（冒烟已有 13 项像素断言）。
5. 关掉主窗口 → 托盘还能再打开（本次已修）。
6. 弹窗有 ✕、Esc 能关（本次已修）。
7. 拖「此电脑」进盒子 → 生成快捷方式（本次已修）。
