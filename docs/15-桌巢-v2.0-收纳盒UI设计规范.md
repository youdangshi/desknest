# 桌巢 v2.0 · 收纳盒 UI 设计规范

> 2026-10-17 · 第二步补充（盒子本身的视觉与交互规格）
> 效果图：`docs/design/box-ui-v2.png`（1:1 合成预览，**不是真机截图**，用来对齐观感）
> 配套：`docs/14` 讲页面结构与交互流程，本文只讲"盒子长什么样、每个像素多大"。

---

## 一、设计目标

1. **一眼看出它是"桌面上的一块区域"，不是应用窗口** —— 无系统边框、半透明、圆角、软阴影。
2. **内容是主角** —— 标题栏只占 30px，图标 40px，名字两行；所有装饰让位。
3. **压在任意壁纸上都看得清** —— 文字按它自己的底色算对比度（≥ 4.5:1），半透明时加描边兜底。

---

## 二、六种形态（效果图里编号 1–6）

| # | 形态 | 什么时候出现 | 关键点 |
| --- | --- | --- | --- |
| 1 | **标准盒** | 默认 | 标题栏 30 高 + 4 个按钮 + 图标网格 |
| 2 | **空盒** | 新建后、文件都移走 | 虚线框 + "把文件拖进来"，不留白板 |
| 3 | **拖拽悬停** | 有文件被拖到盒子上方 | 边框变强调色 2px + 提示"松手放进这个盒子" |
| 4 | **浅色卡片** | 卡片颜色选了浅色 | **文字自动转深**，不会白底白字 |
| 5 | **紧凑** | 右键「标题样式 › 紧凑」 | 标题栏 22 高，省竖向空间 |
| 6 | **悬浮** | 右键「标题样式 › 悬浮」 | 标题栏平时很淡，鼠标移上去才显现 |

## 三、尺寸表（照抄就能画）

| 部件 | 规格 |
| --- | --- |
| 盒子默认尺寸 | **320 × 372**（新盒子）；最小 **160 × 96**；可拉四边/右下角缩放 |
| 圆角 | **12**（可选 0 / 6 / 12 / 18） |
| 边框 | 1px，前景色 **10%** |
| 阴影 | `0 18 40 rgba(0,0,0,.38)` + `0 2 6 rgba(0,0,0,.25)` |
| 标题栏 | 高 **30**（紧凑 22）；内边距 左 10 右 6；元素间距 4 |
| 标题字 | **13 半粗**（紧凑 11.5）；单行，超出省略号 |
| 项目计数 | **11**，前景色 45%，跟在标题后面（如"工作 · 23 项"） |
| 标题按钮 | **22 × 22**，圆角 6，字形 12，按钮间距 2（＋ / ⋯ / ⌄ / ✕） |
| 内容内边距 | **10** |
| 网格 | **4 列**，列间距 4，行高 **86** |
| 格子 | 圆角 8；悬停 = 前景 10% 底 + 1px 强调色描边 |
| 图标 | **40 × 40**，圆角 10（可调 24 / 32 / 40 / 48） |
| 文件名 | **11.5**，最多 2 行截断，行高 1.25，居中 |
| 空态虚线框 | 1.5px 虚线，前景 22%，圆角 8；中间 26 号图标 + 12 号一行字 + 11 号 70% 一行提示 |
| 拖拽提示字 | 12.5，强调色 |

> **列宽公式**：格子宽 =（盒子宽 − 20 内边距 − 12 列间距）÷ 4。例：320 宽 → 72。

## 四、配色

| 项 | 值 |
| --- | --- |
| 深色方案卡片 | `#1B1B1F` 底（亚克力 0.86 时看上去约 `#22222A`） |
| 浅色方案卡片 | `#FFFFFF` 94% |
| 护眼方案卡片 | `#FFFCF4`，字 `#2B2418` |
| 纯黑方案卡片 | `#000000` / 卡片 `#141418` |
| 强调色（默认） | `#4C8BF5` —— 拖拽边框、悬停描边、选中 |
| 危险色 | `#E25353` —— 只用于「删除盒子」 |
| 文字 | **随卡片亮度自动取深/浅**（浅卡片→深字；深卡片→浅字），对比度 ≥ 4.5:1 |
| 标题栏底 | 前景色 **6%**（比正文区略亮一点点，让标题有"栏"的感觉） |

## 五、材质与透明

| 材质 | 观感 | Win10 上 |
| --- | --- | --- |
| **亚克力**（默认） | 半透明 + 轻微模糊 + 略发亮 | 模糊不可用 → 自动降级为"纯色 + 透明"，观感不塌 |
| **云母** | 更透、更贴壁纸 | 同上 |
| **纯色** | 完全按你设的透明度画，最省资源 | 正常 |

- 「材质强度」0.1–1.0（默认 0.65）：强度 ↑ = 更"厚"、更不透明；强度 ↓ = 更透。
- 「透明度」0.25–1.0（默认 0.82）：整体透明程度。
- 两个滑块**都真的会改变画出来的像素**（冒烟有 13 项断言，改了就变）。

## 六、交互反馈（每个动作给什么回应）

| 动作 | 反馈 |
| --- | --- |
| 鼠标移到格子上 | 格子出现 10% 淡底 + 1px 强调描边（0.1s 淡入） |
| 按下并拖动标题栏 | 窗口跟手移动；到屏幕边缘 8px 内自动吸附对齐 |
| 拖动四边/右下角 | 出现缩放手柄；小于 160×96 时停在最小值 |
| 拖文件到盒子上方 | 边框变强调色 2px + 中间提示"松手放进这个盒子" |
| 松手（文件） | 先显示"正在移动…"，成功→图标出现；失败→红色提示并说明原因（被占用/无权限） |
| 拖文件出盒子 | 标准系统拖放，带真实路径；拖到"移动"目标则从盒子记录里移除 |
| 双击标题栏/空白 | 盒子隐藏，右下角出现「撤销」4 秒 |
| 右键 | 12 项菜单（见 docs/14 §4.2），勾选态 = 现状 |
| 滚轮 | 图标大小 24→32→40→48 循环 |
| 文件在外部被删 | 图标变灰 + 角标"!"，双击给一句"文件已不在原位置" |
| 右键拖动（Esc 取消） | 暂不做（v2.0 保持简单） |

## 七、高度自适应内容（**已定：要**）

**问题**：效果图 1 号盒（8 个文件、372 高）下方留了一大片空白，看着像"没装东西"。
**建议**：盒子高度**跟着内容走**——行数 × 86 + 标题栏 + 内边距，最小 200、最大不超过屏幕 70%；
右键「更多操作 › 高度自适应内容」可关（关掉就回到你手拉的大小）。
**好处**：1 个文件也是个紧凑的小盒子，桌面更干净。

## 九、验收

1. 六种形态各截一张图（自动截图模式 + 手动摆位），与效果图对比。
2. 每个配色 × 明暗壁纸：文字对比度 ≥ 4.5:1（已有回归测试）。
3. 冒烟验证器：改卡片颜色 / 材质 / 强度 / 透明度，画出来的像素必须变（已有 13 项）。
4. 鼠标动作按上表逐条手测（本机注入无效，必须你亲手点）。
