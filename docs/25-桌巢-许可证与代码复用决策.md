# 许可证与代码复用决策（ADR-001）

- 日期：2026-10-17
- 状态：**已生效**（由项目负责人拍板 B）
- 影响面：整个仓库、安装包、文档、将来所有提交

## 1. 决定

**DeskNest 从 MIT 切换为 GNU GPL v3.0**，目的是可以直接复用 [DeskBox](https://github.com/Tianyu199509/DeskBox)（GPL-3.0）的代码与界面实现。

## 2. 背景

- 项目原为 MIT，规划里明确写「只借鉴思路、不抄代码/素材」；
- 实测收纳盒的分组标签、胶囊收起、组合排列这几块交互，DeskBox 已经做得很完整；
- DeskBox 的 LICENSE 是 **GNU GPL v3**（`raw.githubusercontent.com/Tianyu199509/DeskBox/main/LICENSE` 已核）；
- GPL 有传染性：把 GPL 代码放进 MIT 项目，整个作品必须按 GPL 分发 —— 这叫许可混用，不能"局部 MIT、局部 GPL"糊过去。

## 3. 备选项

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| A 保持 MIT | 只看交互，代码自己写 | 慢；复杂交互（分组切换、胶囊锚点）容易做得不如它 |
| **B 整体转 GPL-3.0（已选）** | 可直接复用 DeskBox 实现 | 必须开源；将来不能闭源分发、不能做闭源商业版 |
| C 双许可/隔离进程 | 把 GPL 部分做成独立进程走 IPC | 工程复杂度高，边界容易踩线，不划算 |

## 4. GPL-3.0 带来的义务（必须做到）

1. **分发即给源码**：任何人拿到安装包，都能拿到对应版本完整源码（仓库地址写在「关于」页与安装包内）；
2. **保留声明**：不删原作者版权声明与许可文本；本项目的 `LICENSE` 不得替换成更严的条款；
3. **标注修改**：复用/修改自 DeskBox 的文件，文件头写「源自 DeskBox（GPL-3.0），修改说明」；
4. **不额外设限**：不能加"禁止商用""禁止再分发"之类的附加限制；
5. **衍生作品同许可**：基于本项目改的版本也必须 GPL-3.0。

## 7. 风险记录

- **不能反悔成闭源**：除非把 DeskBox 代码全部重写掉，或取得原作者授权；
- 如果将来想做闭源商业版，只有两条路：重写相关模块，或与 DeskBox 作者单独谈授权；
- 我们的图标/字体素材是 MIT（Fluent 图标等），它们**不受影响**，GPL 项目可以包含 MIT 素材，只要保留其声明。

## 补充（2026-10-21）：AGPL 与 GPL 的区别（针对 BongoCat）

- BongoCat 采用 **AGPL-3.0**，比 GPL-3.0 多一条「网络服务条款」：只要通过网络向他人提供该程序的功能，就必须提供源码。
- 把 AGPL 代码并入本项目，**整个桌巢必须改判为 AGPL-3.0**（不能 GPL 与 AGPL 混用）。
- 因此本轮桌宠**只借行为、不借代码与素材**；若日后确需复用某个 AGPL 片段，先在此文档重新决策并接受整体改判。
