# 桌巢 · 收纳盒交互规格（v2.1 草案，2026-10-17）

> 回答「两个盒子合并后标题怎么显示、点标题切到哪个格子、尺寸归谁」。
> 这份是**规格**，不是代码说明；确认后按它改实现，改完逐条验收。

## 0. 一句话规则

**组有一个统一的窗口大小；点标签只换内容，窗口大小不变。**（2026-10-17 你修正：切换时尺寸不跟着成员变）

## 1. 名词

| 名词 | 含义 |
| --- | --- |
| 盒子（格） | 一个真文件夹 + 一份数据记录，有自己的位置、宽高、卷起状态、锁定状态、视图设置 |
| 组 | 2 个以上盒子叠在同一个位置，共用一条标题栏 |
| 成员 | 组里的每个盒子 |
| 当前成员 | 组里此刻正在显示的那一个（同一时刻只显示一个） |
| 锚点 | 组在地面上的左上角坐标（x, y），整组共用 |

## 2. 一个盒子由什么决定

```
┌───────────────────────────────────────┐
│ [▦] 标题 [标签A][标签B]     ⌄  ⚙  ⋯  ✕ │ ← 标题栏（高 30，固定）
├───────────────────────────────────────┤
│  内容区（图标 / 列表，可滚动）           │ ← 高度 = 盒子高 − 30 − 状态行
├───────────────────────────────────────┤
│ 状态行（N 项 · 路径提示）                │
└───────────────────────────────────────┘
   ↑ 四边 12px、四角 40px 都能拖动改大小（对齐微软 7.5mm≈40px 触控目标）
```

- **尺寸**：每个盒子自己的 `Width/Height`，最小 160×96。
- **位置**：单盒时是自己的坐标；进组后由组锚点统一决定。
- **卷起**：每个盒子记住「卷起前高度」；卷起时窗口高 = 30 + 2，标题右侧显示「N 项」（空盒显示「空」，参考 DeskBox 胶囊）。
- **锁定位置 / 锁定尺寸**：单盒时只作用于自己；进组后**升成组级**（见 §6）。

## 3. 合并

### 3.1 三个入口，语义一致

| 入口 | 动作 |
| --- | --- |
| 盒子右键 → 添加格子 → 「＋ B」 | 把 B 并进当前盒 A 所在的组（A 成为当前成员） |
| 把 B 拖到 A 上松手（拖动超过 6px 才算拖，避免误触） | 同上，落点判定保留 24px 外扩 |
| 主窗口 → 概览 → 组件组 → 选两个盒 → 合并 | 同上，A = 第一个下拉框选的盒 |

### 3.2 合并时发生什么

1. 组新建或复用（A 已属于某组就并进那个组）。
2. **锚点 = A 当前左上角**；组的左上角就是 A 的左上角。
3. **组尺寸 = A 的宽高**，B 也统一成这个尺寸（合并后整组一个大小）。
4. 成员顺序 = 加入顺序；A 变成当前成员。
5. 合并后立刻刷新**所有**成员窗口的标签条（不是只刷当前那个）。
6. 不弹窗（合并本身在界面上看得见）。

### 3.3 合并后的窗口尺寸

- 窗口尺寸 = **组尺寸**（合并时定，拉伸时改）。
- 切换成员**不改窗口尺寸**，只换内容与滚动位置。
- 拉伸当前成员 = 改组尺寸（所有成员都记成这个值）。

## 4. 标题栏与标签

- 标题栏从左到右：`▦`（图标）→ 当前成员标题 → 标签条 → 弹性空白 → 4 个按钮（卷起 / 更多 / 菜单 / 关闭，永远贴最右）。
- 标签条：每个成员一个标签，文字 = 盒子名。
  - 当前成员：强调色文字 + 2px 下划线；其余：次要色，悬停变前景色。
  - 名字超过 8 个字截断加省略号。
  - **最多显示 4 个标签，其余收进「▾ 其他 N 个」下拉**（参考 Fences 6 的 "Menu only" 做法）。
  - 右键标签：左移 / 右移 / 移出本组；**把标签拖出盒子范围 = 移出该盒**（参考 Fences 6 的 Shift 拖出）。
  - 成员 ≤ 1 时不画标签条（解散后自动复原）。
- 切换方式三种：**点标签**、**在标题栏空白处滚轮**、**Ctrl+Tab / Ctrl+Shift+Tab**（键盘）。
- 切换动作只做四件事：隐藏当前成员窗口 → 显示目标成员窗口（按目标尺寸）→ 还原它的滚动位置与选中项 → 刷新标签条。不重排文件、不动数据。

## 5. 尺寸、位置、拉伸的所有权

| 操作 | 作用对象 | 结果 |
| --- | --- | --- |
| 拖标题栏 / 拖空白处 | 单盒：自己；组内：**整组** | 锚点变化，所有成员坐标同步 |
| 拉四边四角 | 组内：**整组**（组尺寸） | 窗口变大变小；所有成员记录成同一尺寸；锚点不变 |
| 卷起 `⌄` | 当前成员 | 窗口收到只有标题栏；切到未卷起的成员时恢复组尺寸 |
| 双击标题栏 | 当前成员 | 默认 = 隐藏盒子（可在设置改「卷起 / 什么都不做」） |
| 锁定位置 | 单盒：自己；组内：整组 | 组内锁定时整组都不能拖 |
| 锁定尺寸 | 组内：整组 | 组内锁定时整组都不能拉伸 |

> 记住一条：**位置和大小都是组的；只有内容和卷起状态是个人的。**

## 6. 解散、移出、删除（三个动作，别再混）

| 动作 | 在哪 | 结果 | 会不会动文件 |
| --- | --- | --- | --- |
| **从组里移出** | 组内成员的右键菜单 | 该盒离开组，变独立窗口，落在组左上角 + 错位 24px | 不动 |
| **解散组** | 组内右键菜单（只有 ≥2 个成员才出现） | 所有成员变独立窗口，围绕原位错开排列 | 不动 |
| **删除盒子** | 任何盒子右键菜单 | 盒子消失，里面的文件**还原回原路径**，记录删除 | 会（还原） |

- 「删除盒子」是唯一的破坏性动作，必须有二次确认（菜单项文字写成「删除盒子并还原文件」）。
- 撤销入口不在弹窗里：主窗口「概览」页顶部「最近一次操作 · 撤销」（10 分钟有效）+ 托盘右键「撤销上一次收纳 / 删除」。

## 7. 失败时才提示

| 场景 | 提示方式 |
| --- | --- |
| 锁定尺寸后拉边 | 一条黄色提示，4 秒自动消失，可关 |
| 合并失败（写库异常） | 黄色提示 + 日志 |
| 解散/删除部分文件还原失败 | 黄色提示写明「还原 N 项，失败 M 项」，并给日志入口 |
| 合并成功 / 切换 / 锁定 / 套用样式 / 改名 | **不弹**，靠标签高亮、勾选态、列表变化自己说话 |

## 8. 验收清单（对着做）

**人工**
1. 两个普通盒子：右键 A → 添加格子 → 出现「＋ B」；点它 → A 上出现 B 标签，位置与 A 左上角对齐。
2. **B 比 A 小**：点 B 标签 → **窗口大小不变**，只换内容和滚动位置；点回 A 同样不变。
3. 来回切 5 次：位置不漂、尺寸不跳、文件数不变、滚动位置各记各的。
4. 拖 A 的标题栏 → 整组一起走；拉右下角 → 整组变大，切到哪个成员都是这个新尺寸。
5. 卷起 A → 只剩标题栏；切到 B（未卷起）→ 恢复组尺寸完整显示；切回 A → 仍然卷起。
6. 解散组 → 两个盒子都在，错开 24px，文件没有移动。
7. 删除盒子 → 二次确认 → 文件回到原路径。
8. 上面 1–7 全程**不应出现任何"成功"弹窗**。

**冒烟（自动）**
- `MergeInto`：两个未分组盒子能合并（回归本次 bug）
- 合并后 `group.MemberIds` 顺序 = 加入顺序；所有成员尺寸统一为组尺寸
- `SwitchGroupTo` 只改变可见性，不改任何成员的尺寸与坐标
- 解散组后所有成员 `GroupId = null` 且位置互不重叠
