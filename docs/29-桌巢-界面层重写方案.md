# 桌巢 · 界面层重写方案（WPF + 设计系统）

- 日期：2026-10-20
- 状态：**待确认**（确认后才动代码）
- 前置结论：WinUI 3 迁移在 P0 受阻（见 docs/28 §10），改为「不换框架、重写界面层」
- 目标观感：与 WinUI 3 / Fluent 2 一致（WPF-UI 本身就是 WinUI 的 WPF 移植，做得到）

## 1. 为什么要重写而不是继续修

三轮用户反馈（10-17、10-19 两次）都指向同一个病根：

| 现象 | 真实原因 |
| --- | --- |
| 白底白字、对比度不够 | 颜色是每个控件自己算的，没有统一令牌，改一处漏三处 |
| 按钮不像设计的一部分 | 次要按钮底色用了"卡片白"，在白卡片上等于白按钮 |
| 页面风格不统一 | 五个页面各写各的布局代码，间距/字号随手定 |
| 反复返工 | 没有验收标准，靠肉眼"感觉不对" |

**结论：问题不在 WPF，在没有设计系统。** 所以这次重写的是「界面层」，不是框架。

## 3. 设计令牌（唯一来源：`Ui/Design/DesignTokens.cs`）

| 类别 | 令牌 | 值（浅色 / 深色） | 约束 |
| --- | --- | --- | --- |
| 文字 | `TextPrimary` | 与背景对比 ≥ **7:1** | 正文、标题 |
| 文字 | `TextSecondary` | ≥ **4.5:1** | 说明文字、行副标题 |
| 文字 | `TextTertiary` | ≥ **3:1** | 仅限装饰性计数（如 `2/4`） |
| 表面 | `Surface`（页面底）/ `SurfaceCard`（卡片） | 页面 `#F6F6F8`，卡片 `#FFFFFF` | 卡片必须有 1px 描边或阴影，不能靠"白对白" |
| 描边 | `StrokeSubtle` | 前景色 22% | 按钮、输入框、卡片 |
| 强调 | `Accent` / `AccentHover` / `AccentTint10` | 跟随系统强调色 | 主按钮、选中态 |
| 危险 | `Danger` | 红 600 | 只用于破坏性操作 |
| 间距 | `Space4/8/12/16/24/32` | 4 的倍数 | 禁止 5、7、13 这类魔数 |
| 圆角 | `RadiusControl 6` / `RadiusCard 10` / `RadiusPill 999` | — | 同一类控件只用一档 |
| 字号 | `FontCaption 11` / `Body 13` / `Subtitle 15` / `Title 20` | — | 全项目仅此四档 |
| 动效 | `DurFast 120ms` / `DurBase 200ms` | 缓动 `CubicEase` | 仅用于悬停/展开 |

**对比度红线（写进验收）**：任何一页出图后，逐像素采样必须满足「正文 ≥7、次要 ≥4.5、三级 ≥3」。

## 4. 组件清单（只允许用这些积木搭页面）

| 组件 | 档位 / 规则 |
| --- | --- |
| `Button` | **3 档**：Primary（强调填充 + 自动前景色）/ Secondary（透明底 + 22% 描边 + 10% 悬停）/ Danger（红字）。不写第 4 种 |
| `IconButton` | 30×30、透明底、悬停淡底 |
| `Card` | 白底 + 22% 描边 + 10 圆角；悬停不再变色（卡片不是按钮） |
| `Section` | 卡片 + 标题 + 副标题 + 内容区，页面里只放 Section，不直接堆控件 |
| `Row` | 左标签 / 中说明 / 右控件；三栏固定比例，保证五个页面纵向对齐 |
| `ComboBox` / `TextBox` / `Slider` / `ToggleSwitch` | 统一描边与焦点环，占位文字用 `TextSecondary`（**不允许**低透明度） |
| `Tabs` | 仅用于同页分组（如「外观 / 行为 / 数据」），不做导航 |
| `EmptyState` | 图标 + 一句话 + 一个主按钮 |
| `Toast` | 右下角、最多 1 条、4 秒、带关闭；**成功类不弹**（沿用 10-19 的决定） |
| `Dialog` | 统一标题/正文/两个按钮（主按钮在右） |

## 6. 每个阶段的验收产物（固定格式）

1. `_shots\<阶段>\*.png` 截图；
2. 一张像素对比度表（区域 / 实测值 / 是否达标）；
3. 冒烟结果（Core 层 82 项必须不退化）；
4. 一段 3 行的自评：改了什么、和上一版差在哪、还剩什么。

## 7. 与其它路线的关系

- **WinUI 3**：暂停。docs/28 §10 已记录失败证据；若日后要重启，先解决「XAML 运行时激活」再谈。
- **Avalonia**：不走。它解决的是跨平台，而我们全是 Windows 专有能力（贴桌面层）。
- **DeskBox 复用**：继续只用它的**交互规范**（组选择器、收起四档、排列算法），不抄它的 WinUI 代码（框架不同，抄不动）。
