## 一之三、② 的代码现状（已核对）

`WindowDrag.WrapWithResizeGrips` 其实给四条边各挂了 10px 抓取区、右下角 20px 抓手并画了三点提示；
但用户实测只有左下角能拉。说明"挂了手柄"≠"真的能命中"——要么被 ScrollViewer / 内容层盖住，
要么手柄的命中区域与可见提示错位。修法见 B7。

## 三、流程约定（自本轮起）

1. 每一步**先出设计**（改哪几个文件、交互怎么变、验收标准）→ 你确认 → 才动代码。
2. 改完**自己先验**（编译 0 错误 + 冒烟全过 + 关键截图）→ 再交你人工验。
3. 一条一提交，提交信息写「改了什么 + 为什么」；v2.0 收尾时打 tag（第 6 步 Git 存证）。
4. 产品决策**一次只问一个**。
