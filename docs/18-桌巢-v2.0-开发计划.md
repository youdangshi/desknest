## 一、技术方案总览

### 1.1 不动的部分

- 三层架构不变：`DeskNest.App`（WPF）/ `DeskNest.Core`（数据+逻辑）/ `DeskNest.Native`（Win32）。
- 数据库仍是 SQLite（`%LOCALAPPDATA%\DeskNest`），**只加列、不删列**。
- 构建命令、冒烟验证器、截图模式全部沿用。

### 1.2 关键改动（按层）

| 层 | 改什么 | 手法 |
| --- | --- | --- |
| App/导航 | 15 页 → 5 页 | `MainWindow.RegisterPages()` 只注册 5 个；**页面类不删**，只是不注册、不 new |
| App/模块 | 6 个模块不进默认构建 | `DeskNest.App.csproj` 注释掉 6 个 `ProjectReference`；`CopyModules` 目标排除 |
| Core/数据 | 每盒卡片颜色 | `BoxRecord.CardColor` + `Db.EnsureColumn("boxes","card_color","TEXT DEFAULT ''")` + `Repository` 读写（**列追加到末尾**，避免位置索引错位） |
| Core/收纳 | 真移动三步校验 | 新增 `FileOps.MoveVerified(source, target)`：可写+空间 → 同卷 `File.Move` / 跨卷 复制→校验→删源 → 失败保留源 |
| App/盒子 | 高度自适应 | `BoxWindow`：`ItemsChanged` 时算 `行数×86+30+20`，夹在 [200, 屏高×70%]；手动缩放后置 `HandSized=true` 停止自动 |
| App/托盘 | 单击/双击判定 + 菜单 5 项 | 260ms `DispatcherTimer`：单击延时执行，双击取消 |
| App/热键 | 可配置全局热键 | `Native/Win32/GlobalHotKey` 已有注册能力，扩成"可注销+可重注册"；KeyGesture 字符串 ↔ 修饰键映射 |
| App/设置 | 新键 | `hotkey.toggleBoxes`（默认 `Ctrl+Alt+H`，空=关）、`theme.forceOpaqueShell`（已有） |

### 1.3 明确不做（避免手滑）

不碰整理、搜索、组件、多显示器页、模块加载器、`docs/10` 的验收记录（等发版再补）。

## 六、风险与回滚

| 风险 | 对策 |
| --- | --- |
| 摘模块/摘页面把 build 弄坏 | 每次只改一处 + 立刻编译；坏了一键 `git checkout` 单个文件 |
| 真移动丢文件 | 三步校验 + 跨卷先复制后删 + 失败保留源；冒烟覆盖 6 条 |
| 高度自适应和手动大小打架 | 用 `HandSized` 标记，谁最后动听谁的 |
| 热键注册失败把自己搞没 | 冲突时保留旧值，绝不注销旧键 |
| 老库读崩 | 所有新列给 DEFAULT；可空列用 `GetXxxOrNull` |
| 下架功能以后补不回 | 页面/模块代码一律保留，只拔入口 |

## 七、完成定义（DoD）

1. 5 个页面、导航无死入口、无英文枚举值。
2. 收纳闭环（建 → 拖入 → 打开 → 移出 → 删盒）9 条手测全过，0 文件丢失。
3. 外观/卡片颜色/高度自适应/热键/托盘 全部可用且可关。
4. 编译 0 错误；冒烟 ≥ 66 项全过；截图 5 页正常。
5. `docs/10` 验收记录、`CONTEXT.md` 快照、`docs/17` 状态同步；版本号 2.0.0。
