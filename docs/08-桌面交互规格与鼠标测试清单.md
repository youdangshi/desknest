## 0. 图层总览（从桌面往内看）

```
① 桌面层（挂在壁纸之上、图标之下，不抢焦点、不进任务栏）
   ① -A 收纳盒窗口（可多个，可编组）
   ① -B 桌面组件窗口（待办/随记/天气/音乐/系统监视/概览/文件）
   ① -C 桌宠窗口（可拖动、可点击互动）
② 应用层（普通窗口，会抢焦点）
   ② -A 主窗口（左栏导航 + 顶部搜索 + 卡片式设置页）
   ② -B 快捷搜索面板（Alt+Space）
③ 系统入口
   ③ -A 托盘图标与菜单
   ③ -B 全局热键（Alt+Space / Alt+`）
   ③ -C 双击桌面空白（切换桌面图标）
```

**鼠标在各层的行为有本质区别**：桌面层窗口**点一下会激活自己**（这样输入框、右键菜单才能用），但**不会被移到最前**（它永远在普通窗口之下）；应用层窗口按普通 Windows 窗口规则走。

## 一、①-A 收纳盒窗口：逐个元素 × 逐个鼠标动作

### 1.1 结构（从上到下）

| 区域 | 内容 |
| --- | --- |
| **标题栏**（30px） | 左：▦ 图标 + 盒子名称 + （编组时）标签条；右：**＋** 添加文件、**⋯** 更多、**⌄** 卷起/展开、**✕** 隐藏 |
| **内容区** | 图标视图（图标 + 最多两行文件名）或列表视图（图标 + 名称 + 大小）；空盒显示虚线空态框 |
| **底部状态条** | 「N 项 · 合计 X GB」 |
| **缩放手柄** | 右下角 14×14 手柄 + 四条 6px 透明边 |

### 1.2 标题栏上的鼠标动作

| 动作 | 结果 | 状态 |
| --- | --- | --- |
| 左键**按住拖动** | 盒子跟着鼠标移动（走系统原生移动循环，多显示器/DPI 都跟手） | ✅ 带限流的落盘（每 250ms 一次，松手立即写） |
| 左键**双击** | 卷起 / 展开（卷起只留标题栏） | ✅ |
| 左键单击 **＋** | 打开"选择文件"对话框，选中的文件被**移动**进盒子（映射盒只记路径） | ✅ |
| 左键单击 **⋯** | 展开盒子菜单（见 1.4） | ✅ |
| 左键单击 **⌄** | 卷起 / 展开 | ✅ |
| 左键单击 **✕** | 隐藏该盒（托盘里可再显示） | ✅ |
| 左键单击**标签条上的其它标签** | 切换到同组的另一个盒子 | ✅ 编组后才有 |
| 右键标题栏 | 与 **⋯** 相同的盒子菜单 | ✅ |
| 悬停标题栏 | 出现提示「按住标题栏拖动盒子；右下角或任意边拖动可调整大小」 | ✅ |
| 锁定位置 ⚙️ 后拖动 | **不动** | ✅ |

### 1.3 内容区上的鼠标动作

| 动作 | 结果 | 状态 |
| --- | --- | --- |
| 左键**双击**文件项 | 用系统默认程序打开；文件已不在原位置时标记"失效"并提示 | ✅ |
| 左键**单击**文件项 | 目前无选中态（不需要按住 Ctrl 多选） | 🔜 多选 + 拖拽 |
| 右键文件项 | 文件菜单（见 1.5） | ✅ |
| 滚轮 | 内容区上下滚动 | ✅ |
| `Ctrl` + 滚轮 | 图标大小 18–72px 实时变化并记住 | ✅ |
| 滚轮（**在盒组里**） | 切换同组的盒子（⚙️ `group.wheelSwitch`） | ✅ |
| **把盒子拖到另一个盒子上** | 双方描边高亮 + 底部提示「松开合并到「X」」；松手即合并成组。<br>自己、隐藏的盒子、已经在同一组里的盒子**不会**提示（避免误合并）；命中范围向外放宽 24px，不必精确压在边缘 | ✅ |
| 从资源管理器**拖文件进来** | 盒子描边高亮 2px 强调色；松手后文件进盒、播放落位动画 | ✅ |
| 拖**文件夹**进来 | 同文件（整目录移入） | ✅ |
| 拖到**映射盒** | 只登记路径，源文件不动 | ✅ |
| 把文件项**拖出去**（拖到桌面/资源管理器/聊天窗口） | 标准 OLE 拖放，带出去的是文件当前真实路径。<br>目标执行**移动**（桌面、资源管理器）→ 文件被搬走，盒子里的记录自动删除；<br>目标执行**复制**（聊天窗口等）→ 记录保留。<br>注意：这样拖是"落到你松手的地方"，想还原到**原位置**请用右键菜单的「从盒中移除」 | ✅ |
| 右键盒子**空白处** | 盒子菜单（与 ⋯ 相同） | ✅ |
| 空盒时双击空态框 | 无动作（空态里写着"把文件拖进来"） | ✅ |
| 移动到"锁定尺寸"的盒子上拖右下角 | **不缩放** | ✅ |

### 1.4 盒子菜单（⋯ 或右键盒子空白处）全条目

| 菜单项 | 作用 |
| --- | --- |
| 添加文件… | 与 ＋ 相同 |
| 打开存储文件夹 | 用资源管理器打开这个盒的托管目录 |
| 切换为列表视图 / 图标视图 | 视图切换 |
| 切换排序方式（名称 / 加入时间 / 大小） | 循环切换 |
| 显示文件名 / 隐藏文件名 | 图标下是否显示名字 |
| 开启自动隐藏 / 关闭自动隐藏 | 鼠标离开后透明度降到 35% |
| 单独设置样式 / 样式跟随全局 | 两级样式的开关（全局 vs 本盒） |
| 锁定位置 / 解锁位置 | 防误拖 |
| 锁定尺寸 / 解锁尺寸 | 防误缩放 |
| 把我的外观应用到所有盒（统一样式） | 一键统一 |
| 删除盒子（盒内文件还原到原位置） | 二次确认；逐个还原，原位置不存在则回退桌面 |

### 1.5 文件项菜单（右键文件）

| 菜单项 | 作用 |
| --- | --- |
| 打开 | 同双击 |
| 在资源管理器中显示 | 打开所在文件夹（目录则直接进入） |
| 复制路径 | 复制完整路径到剪贴板 |
| 重命名… | 弹窗输入新名；**存储的文件实体一起改名**，还原时用新名 |
| 固定到顶部 / 取消固定 | 置顶显示 |
| 移动到其他盒子… | 列出其它盒（最多 12 个），移动并登记到目标盒 |
| 从盒中移除（文件还原到原位置） | 还原 + 10 秒内可"撤销"（把文件放回盒里） |

### 1.6 缩放手柄

| 动作 | 结果 |
| --- | --- |
| 拖右下角 | 宽高同时变（最小 160×96） |
| 拖右边 / 左边 | 只改宽；拖左边时**对边保持不动** |
| 拖下边 / 上边 | 只改高；拖上边时**对边保持不动** |
| 悬停手柄 | 光标变成对应方向的缩放箭头；右下角有"拖动调整大小"提示 |
| 松手 | 尺寸与位置写入数据库，重启后保持一致 |

## 二、①-B 桌面组件窗口

### 2.1 通用标题栏

| 元素 / 动作 | 结果 |
| --- | --- |
| ▢ + 名称 | 标识组件类型 |
| 按住标题栏拖动 | 移动（同盒子） |
| **⋯** | 菜单：刷新 / 单独设置样式 / 透明度 + / 透明度 − / 从桌面移除组件 |
| **⌄** | 折叠成只有标题栏（再点展开） |
| **✕** | 隐藏（可在"桌面组件"页再显示） |
| 拖右下角或四边 | 缩放并记忆 |

### 2.2 各组件内的鼠标动作

| 组件 | 鼠标动作 → 反应 |
| --- | --- |
| **待办** | 顶部输入框回车=添加任务；点复选框=完成（计数与完成率更新）；**右键任务**=设为高/中/低优先级、提醒（5 分钟后）、删除 |
| **随记** | 点「＋ 新建随记」=新建；点正文=直接编辑，**点别处=自动保存**（底部显示"已保存 HH:mm:ss"）；点「固定/取消固定」=置顶；点「删除」=删除该条 |
| **天气** | 点「刷新」=拉取 Open-Meteo 数据；点「设置城市」=弹窗输入城市（保存后立即刷新） |
| **音乐** | 点 ⏮ / ⏯ / ⏭ = 给当前播放器发媒体键（不需要任何权限） |
| **系统监视** | 无交互；每秒刷新 CPU / 内存 / 网络 / GPU 读数 |
| **概览** | 点「一键整理」=打开整理向导；点「搜索」=打开快捷搜索面板 |
| **文件组件** | 双击条目=打开；未绑定盒子时点「去绑定」=绑定第一个收纳盒 |

## 五、②-B 快捷搜索面板（Alt+Space）

面板固定在屏幕水平居中、纵向偏上（约屏幕高 22%），宽 680、高 460。

| 鼠标动作 | 结果 |
| --- | --- |
| 点输入框 | 聚焦，可直接输入 |
| 输入文字 | 实时过滤（本地索引，无防抖延迟） |
| 点结果行 | 选中该行（高亮） |
| **双击**结果行 | 打开 |
| 点 [✕] / 点面板外 / 失焦 | 关闭面板 |
| 滚轮 | 结果列表滚动 |

| 键盘 | 结果 |
| --- | --- |
| `↑` / `↓` | 上/下选择 |
| `Enter` | 打开选中项（命令类则执行） |
| `Ctrl` + `Enter` | 打开所在位置 |
| `Esc` | 关闭 |
| `/` 前缀 | 切到命令模式（`/整理`、`/新建盒`、`/隐藏图标`、`/打开设置`…） |

## 八、"适应人眼"的具体指标（可对照检查）

| 项 | 取值 | 为什么 |
| --- | --- | --- |
| 正文对比度 | **≥ 4.5:1**（四套配色实测，有 9 项回归测试） | WCAG AA，长时间看不累 |
| 次要文字 | ≥ 3:1；更弱的辅助文字 ≥ 2:1 | 层级分明又不糊 |
| 正文/说明字号 | 13 / 12（设置项标题 14、页面标题 28） | 中文小字号可读性下限 |
| 行高 | 48–64（设置行 64） | 眼睛扫行不容易串行 |
| 点击热区 | 按钮高 34、最小宽 104；图标按钮 30×30；缩放手柄 14 | 不小于手指/鼠标精度下限 |
| 内容列宽 | ≤ 840 | 一行不超过 ~90 个字符，避免"眼睛长跑" |
| 颜色数量 | 一个模块一个色调（导航 7 色） | 靠位置+图标识别，不靠满屏彩色 |
| 动效时长 | 120–320ms，切换落定 < 350ms | 超过 400ms 会被感觉"卡" |
| 减少动效 | ⚙️ 一键降级为淡入淡出 | 前庭敏感/低配机器 |
| 深/浅/护眼/纯黑 | 四套都实测对比度；护眼为浅底暖白 | 夜间与长时间阅读 |
| 透明度 | 盒与组件默认 0.82，可调到 0.3–1.0 | 既要看清桌面壁纸，也要看清字 |
| 提示语 | 每个空态、加载态、错误态都有中文说明 | 不留"白屏猜谜" |
