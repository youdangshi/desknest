## 2. 为什么不能直接抄

| 障碍 | 说明 |
| --- | --- |
| **语言栈不同** | 它是 C/C++ + SDL3 + OpenGL；我们是 C# + WinUI 3 / WPF。代码抄过来等于重写 |
| **协议会拽走整个项目** | AGPL-3.0 与 GPL-3.0 不同：AGPL 的网络条款要求「通过网络提供服务时也必须开源」。把 AGPL 代码并入本项目，**整个桌巢就得改判为 AGPL-3.0**（我们刚在 docs/25 定的是 GPL-3.0） |
| **Live2D 有独立授权** | Cubism SDK 不是开源库，有独立许可与分发条件；模型本身还有作者版权（BongoCat 演示模型来自 B 站作者） |
| **素材不能带** | 它的图标、模型、音效都不属于我们，不能随桌巢分发 |

一句话：**抄的是「喵在桌面上敲键盘」这个主意，而这个主意不受版权保护；代码、模型、素材都受。**

## 3. 我们要「抄」的具体清单（行为层）

按价值排序，全部是产品行为，不涉及它的代码：

1. **贴桌面层**：宠物和其它窗口一样可以被普通窗口盖住，而不是永远置顶（置顶会挡操作）。
2. **输入联动**：键盘按下 → 抬头/敲击；鼠标移动或点击 → 视线跟随/挥爪；停止输入 N 秒 → 打盹。
3. **动作库**：idle / type / click / drag / sleep / celebrate，每套 3–10 帧，帧率 8–12fps 即可（不需要 60fps）。
4. **可换素材**：模型包与程序分离（我们的 `.petpack` 格式在 docs/10 里已有雏形），支持用户放自己的图。
5. **不打扰**：默认静音、默认不置顶、可一键隐藏；鼠标穿过还是可点，做成设置项。
6. **位置记忆**：拖动后记住位置；多显示器按屏幕标识记。
7. **冷启动成本**：宠物是独立小模块，删掉 dll 就等于没这功能（沿用 docs/10 的模块化约定）。

## 4. 我们的实现路线（WinUI 3）

| 层 | 做法 | 复用 |
| --- | --- | --- |
| 窗口宿主 | 无边框透明窗口 + `owner = WorkerW` + `WS_EX_TOOLWINDOW`（进不了 Alt+Tab） | **P0 已验证**（docs/28 §10.5） |
| 渲染 | WinUI `Image` 切帧 或 `CompositionTarget` 逐帧；先用 PNG 序列，够用再考虑 Lottie | 新建 |
| 输入联动 | 全局键鼠钩子（`SetWindowsHookEx` / Raw Input）→ 事件总线 → 动作状态机 | `DeskNest.Native` 已有钩子与热键基础 |
| 素材 | `.petpack`（zip：`pet.json` + `frames/*.png` + 可选音效），自带校验与尺寸检查 | Core 的 zip/文件工具 |
| 设置 | 新增「桌宠」页：显示/隐藏、置顶、大小、动画速度、是否穿透、素材切换 | WinUI 设置页 |
| 数据 | 位置/大小/素材 id/开关 存 `settings` 与 pets 表 | Repository 迁移 |

**不采用 Live2D**：Cubism SDK 授权与体积都不划算，先做帧动画。若以后要上 Live2D，单独评审。

## 5. 任务拆分（进 docs/18）

| 编号 | 任务 | 验收 |
| --- | --- | --- |
| **T28** 宠物窗口宿主 | 透明无边框窗 + owner 宿主 + 不进 Alt+Tab + 位置记忆 | 拖动后重启位置不变；被普通窗口盖住；Alt+Tab 看不到 |
| **T29** 动作播放器与状态机 | idle/type/click/drag/sleep 六态；输入触发与冷却 | 打字时切 type，停 5 秒回 idle，拖动时 drag |
| **T30** 输入联动 | 全局键鼠事件 → 动作映射；可关 | 关掉后宠物不再跟手；不影响系统输入延迟（自测 <5ms 无感） |
| **T31** `.petpack` 素材包 | 打包/校验/导入/切换 | 导入一个自带测试包后能换形象；坏包不崩、给出原因 |
| **T32** 设置页与托盘项 | 显示/隐藏、置顶、大小、穿透、静音、素材 | 五项设置都能即时生效；托盘可一键隐藏 |

## 6. 合规红线（写进发布检查表）

1. **不带任何 BongoCat 素材**（模型、图标、音效）；
2. 不复制 BongoCat 代码；如需复用某个算法，**必须**在文件头写 `// 源自 BongoCat (AGPL-3.0) https://github.com/vladelaina/BongoCat，已修改：…` 并接受**整个项目改判 AGPL-3.0**；
3. 用户自备素材（.petpack）由用户承担版权；
4. 内置示例宠物必须是我们自己画的或用 CC0 素材，并在 THIRD-PARTY-NOTICES 里写明来源。
