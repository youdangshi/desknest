| 项 | 内容 |
| --- | --- |

---

## 1. 背景与目标

### 1.1 为什么做 v2.0

v1.1 有 15 个设置页、7 类组件、6 个可选模块，功能很多但**核心的那件事（把桌面文件收起来）反而不够稳**：
历史事故里"文件被顺手搬走找不到""盒子拖不动""外观改了没反应"都出在核心链路上。v2.0 把外围全部下架，只把这一条链路做到"闭着眼也敢用"。

### 1.2 目标（可度量）

| # | 目标 | 度量 |
| --- | --- | --- |
| G1 | 收纳链路零数据事故 | 100 次拖入/移出/删盒，0 个文件丢失；失败必留原件 |
| G2 | 上手不用看说明 | 新用户 60 秒内建成第一个盒子并放进 1 个文件 |
| G3 | 桌面真的变干净 | 收纳后桌面图标数按预期减少（由用户自己数） |
| G4 | 轻 | 冷启动 ≤ 1.5s；常驻内存 ≤ 120 MB；发布包 ≤ 75 MB（单文件压缩） |
| G5 | 不吓人 | 首次运行不弹权限框、不联网、不写注册表（除开机自启开关） |

### 1.3 非目标

不做搜索、不做整理、不做待办、不做桌宠、不做云同步、不做多语言（文案先抽资源但只出中文）。

## 2. 用户与场景

**用户**：单休上班族，桌面常年堆下载文件/截图/工程目录；要"桌面干净 + 点两下能找到 + 不要广告"。

| 场景 | 步骤 | 成功标准 |
| --- | --- | --- |
| S1 第一次用 | 打开 → 概览页引导 → 新建盒子"工作" → 拖 3 个文件进去 | 桌面少了 3 个图标，盒子里多了 3 个 |
| S2 每天找东西 | 看桌面盒子图标 → 双击打开 | ≤ 2 次点击打开文件 |
| S3 不想要了 | 右键盒子 → 删除 → 勾选确认 | 文件回到原来的桌面位置 |
| S4 桌面要干净 | 托盘左键单击 | 所有盒子隐藏/恢复 |

## 4. 功能需求（编号 = 开发与验收的锚点）

### FR-01 新建收纳盒

- 入口：概览页「＋ 新建收纳盒」、收纳盒页右上、托盘右键「新建收纳盒…」。
- 字段：名称（1–40 字，禁 `\\ / : * ? " < > |`，不与现有盒子重名）、类型（普通/映射）、存储位置（默认 `<数据目录>\boxes\<盒子ID>`，可改）、映射路径（映射盒必填且目录必须存在）。
- 规则：**只创建空盒子，绝不移动任何文件**；创建后盒子出现在桌面（主屏可见区域，避免叠在屏幕外）。
- 验收：新建后桌面出现空盒子、数据目录多一个空文件夹、概览卡片 +1；**桌面文件的修改时间不变**。

### FR-02 拖入文件（核心）

- 拖入来源：桌面/资源管理器/其他程序（`CF_HDROP`）。
- 规则（**已定：真移动**）：
  1. 目标路径 = 盒子存储目录；重名自动加 ` (1)`、` (2)`。
  2. 移动前先校验：目标目录可写、剩余空间 ≥ 文件大小。
  3. **同一卷**：原子移动；**跨卷**：复制 → 校验大小 → 删除源文件（中途失败**保留源文件**并报错）。
  4. 成功后写 `items` 记录（`source_path` = 原路径，`stored_path` = 新路径）。
  5. 大文件显示进度，可取消（取消 = 尽力回滚到原位）。
6. **同一个文件重复拖入**：不重复建记录，提示「这个文件已经在盒子里了」（按 `source_path` 判重）。
- 验收：拖 1 个 1.2 GB 文件跨盘，进度可见、可取消、取消后原文件还在；重复名加后缀不覆盖。

### FR-03 映射盒收纳

- 拖入只写一条引用（`item.source_path`），**不动任何文件**。
- 验收：拖入后原文件仍在原处；盒子里出现图标；删引用不影响原文件。

### FR-04 打开与浏览

- 双击条目：文件→默认程序；文件夹→资源管理器（v2.0 不做盒内浏览）；快捷方式→目标；系统图标快捷方式→对应 shell 位置。
- 双击盒子标题栏/空白：隐藏盒子（提示可撤销 4 秒）。
- 验收：每类条目双击都有明确结果，失败给一句人话。

### FR-05 移出盒子（单条）

- 右键条目「移出盒子」：把文件**还原到 `source_path`**；原目录不存在→桌面；重名加后缀。映射条目只删记录。
- 验收：移出后文件回到原位；原位置被删掉时落到桌面并提示。

### FR-06 删除盒子

- 必须勾选"我明白，文件会从盒子里移走"才能点删除；映射盒只需提示"不动文件"。
- 执行：逐条还原（FR-05 规则）→ 删记录 → 删空目录；显示"还原中 3/23"，失败项列出来可重试/跳过。
- 验收：23 项全部还原；结束后盒子消失、提示"2 个放到了桌面"。

### FR-07 盒子窗口交互

拖动（手动增量 + DPI 换算）· 四边/右下缩放（最小 160×96）· 卷起/展开 · 隐藏 · 图标/列表视图 · 滚轮改图标大小 · 锁定位置/尺寸（锁定时给"已锁定"提示）。

### FR-08 右键菜单

按 `docs/16` §12.2 的 12 项（含三级子菜单、「跟随全局（当前值）」、置灰附原因、危险项红色）。
- 验收：每一项都能点、勾选态等于现状、不能点的项写清原因。

### FR-09 外观

两套令牌（设计窗口/收纳窗口）× 6 行（配色 5 值 / 卡片颜色 9 色块+自定义 / 材质 3 值 / 强度 0.1–1.0 / 透明度 0.25–1.0 / 圆角 0–28）+ 三个动作（统一、互相复制）+ 主窗口背景开关（Win10 默认不透明）。
- 验收：改任何一项→桌面盒子当场变；浅色卡片→文字自动转深；冒烟像素断言全过。

### FR-10 高度自适应

- 高度 = 行数 × 86 + 30 + 20，最小 200，最大屏高 70%。
- **一旦用户手动拖过边框改大小**，这个盒子自动切成「手动大小」（自适应暂停，记录 `auto_height=0`）；
  右键「高度自适应内容」再点一次才恢复自动。
- 验收：1 个文件的盒子明显比 8 个文件的矮；手动拉高后加文件不再自动变高。

### FR-11 托盘

- 左键单击 = 显示/隐藏桌面上所有盒子（与热键、右键菜单项是**同一个开关**，三处入口状态必须一致）。
- 双击 = 打开主窗口（**已定 A 方案**：单击清屏、双击打开设置；双击时抑制掉其中一次切换，见 FR-11.1）。
- 右键 = 5 项菜单（含「设置…」二级 5 页）+ 退出。
- 悬停 = 气泡"桌巢 · 3 个盒子"。
- 验收：左键能一键清屏；关掉主窗口后还能从托盘打开（v1.1 的 bug 不得回归）。

#### FR-11.1 单击 / 双击的判定（避免"双击触发两次切换"）

系统会把双击拆成"单击 → 双击"两次事件。规则：

- 单击后**等 260ms**：这期间没有第二下 → 执行"切换盒子"。
- 若 260ms 内来了第二下 → 视为双击 → **不执行切换**，改为打开主窗口。
- 260ms 的延迟只在"单击"路径上；双击路径无延迟。

### FR-15 全局热键：隐藏/显示所有盒子

- 默认 **Ctrl + Alt + H**（可在设置里改，也可以关掉）。
- 作用：**所有盒子一起隐藏 / 恢复**（不是单个）。隐藏时给一次托盘气泡"盒子已隐藏，Ctrl+Alt+H 可恢复"。
- 与 FR-11 的关系：热键、托盘左键、右键菜单项 **共用一个状态**（`layerVisible`），任何一处改，其余两处立刻反映。
- 设置入口：「概览」页 →「快捷操作」小节：`隐藏/显示所有盒子  [Ctrl+Alt+H]  [修改]  [开关]`。
- 修改方式：点击「修改」→ 输入框进入录制态（"请按下组合键…"）→ 按下组合键即生效；Esc 取消。
- 冲突处理：注册失败（被别的软件占用）→ 提示"这个组合键被占用了，换一个"并**保留原热键不变**；不允许注册单键或纯字母（必须含 Ctrl/Alt/Win 之一）。
- 关掉开关 = 注销热键，功能完全不可用（满足"每个功能都能单独关掉"）。
- 验收：改完热键立刻生效；关掉后按原组合键无反应；重启后热键仍在（落盘）；冲突时旧热键还能用。

### FR-12 备份与回滚

立即备份（设置+数据库+盒子清单，带时间戳；**不包含盒内的实际文件**，回滚只恢复记录、不动文件）／从备份回滚（选择列表 + 二次确认 + 先自动备份现状）／打开数据目录／生成诊断包（**不含密钥**）。

### FR-13 检查更新

点按钮才联网；三态（最新/有新版本/失败）；失败只给一句中文；可关。

### FR-14 单实例与自启

已有实例时唤出主窗口；自启默认关，开关写在设置里（可单独关）。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 冷启动 ≤ 1.5s；拖入 100 个文件批量移动 ≤ 3s（同卷）；UI 操作无卡顿（>16ms 的阻塞要挪到后台） |

| 安全 | 密钥不落明文（DPAPI）；诊断包自动脱敏 |
| 可维护 | 每功能可单独关；下架功能不进默认构建但代码保留 |

## 7. 异常与边界（每条都要有文案）

| 场景 | 处理 |
| --- | --- |
| 文件被占用 | "文件正在被其它程序使用" + 重试/跳过 |

## 8. 验收标准（DoD）

**任何一条不满足就不算完成：**

1. 编译 0 错误；冒烟 `tools/DeskNest.Smoke` 全过（含像素断言）。
2. `--shot-pages` 能跑完 5 页 + 桌面层，退出码 0；关键页人工看一遍。
3. 真机手测（鼠标注入无效，必须人点）：
   - 新建盒子只建空盒子（桌面文件修改时间不变）
   - 拖入 3 个文件 → 桌面少 3 个、盒子里 3 个
   - 移出 1 个 → 回原位
   - 删盒子 → 全部回原位（含"原位置不存在→桌面"）
   - 改卡片颜色/材质/透明度 → 盒子当场变
   - 关闭主窗口 → 托盘能再打开
   - 弹窗有 ✕、Esc 能关
   - 托盘左键 → 全部盒子隐藏/恢复
   - **热键 Ctrl+Alt+H → 全部盒子隐藏/恢复**；改成别的组合键后仍然生效；关掉开关后无反应
   - **双击托盘 → 只打开主窗口，不会出现"盒子闪一下又回来"**
   - 高度自适应：1 个文件的盒子明显变矮
4. 备份 → 改动 → 回滚，数据回到备份时点。
5. 5 个页面无死入口、无英文枚举值、无"点了报错"。

| # | 决策 | 落地到哪 |

| D1 | **盒子改名不改文件夹**：存储目录命名 `<数据目录>\\boxes\\<盒子名>-<ID前8位>`；改名只改显示名 | FR-01；改名后不移动任何文件 |

| D9 | 检查更新**默认关**，点了才联网 | FR-13 |
| D10 | 版本号 **2.0.0**；老库自动升级（EnsureColumn） | §6 |

### 12.1 由 D1 引出的两条配套规则

- 新建盒子时文件夹名里的盒子名会先清洗（去掉 `\\ / : * ? " < > |`，超长截断到 40 字符）；清洗后为空就只用 ID。
- 改名后旧文件夹名**保持不变**；「打开存储文件夹」永远打开当前记录里的那个路径。
