## 1. 一页纸结论

**产品**：桌巢 DeskNest —— Windows 10/11 上的桌面管家，四块能力 + 一堆可选模块：

1. **桌面整理**（收纳盒 / 分区 / 一键整理 / 规则整理 / 全盘搜索 / 可撤销）
2. **桌面组件**（待办、随记、天气、音乐、系统监视、概览 + 组件组 + 胶囊模式）
3. **工作伙伴桌宠**（打字跟随 + 待办/番茄钟/休息/系统状态联动 + AI 问答入口）
4. **可选工具模块**（应用使用统计、性能监视、API 面板、计划关机、截图录屏 GIF、AI 接口）——**装不装、开不开，全部由你决定**

**红线**：开源（GPL-3.0）、不弹广告、不做推广位、不注册系统右键菜单、不注入 Explorer、不静默上传任何数据、基础功能不做付费墙。

**技术**：.NET 10 + WPF 三层（App/Core/Native）+ SQLite + 自研 Win32 互操作；桌面层不注入，缩略图等重活放独立进程。

**交付**：一次做到 v1.0，闭环测试通过后给你可运行版本；GitHub 建仓，每个版本都推。

## 2. 技术路线（大白话版）

> 你是小白，所以这一节我用"盖房子"的方式讲，尽量不用术语；术语出现时我会立刻翻译。

### 2.1 一句话版本

我们不是"写一个窗口程序"，而是**盖一栋小楼**：地基（数据）→ 承重墙（逻辑）→ 水电（和 Windows 打交道）→ 装修（界面）。四层分开盖，好处是任何一层出问题都不会拖垮整栋楼，而且以后想换装修风格不用砸墙。

### 2.2 我们用什么"材料"，为什么要它

| 材料 | 大白话解释 | 为什么选它 |
| --- | --- | --- |
| **.NET 10** | 微软的"程序运行底座"，相当于建材标准。装上它，程序才能跑 | 免费、跨平台、长期支持；你这台机器我已经装好了（私有目录，没污染系统） |
| **WPF** | 微软做 Windows 桌面界面的"装修工具箱"，能做出半透明、圆角、动画这些效果 | 做"悬浮在桌面上的半透明盒子"这类需求，它最稳；竞品 WitchDrawer 就是用它，路已被验证 |
| **C#** | 写程序的"语言"（像英语之于写作） | 上手快、库多、出错信息友好 |
| **SQLite** | 一个**单文件数据库**，所有盒、文件记录、待办、规则都存里面，就像一本 Excel 账本 | 不需要装数据库服务；断电也不容易坏；方便备份（拷一个文件） |
| **Win32 互操作** | Windows 系统最底层的那套"操作系统调用"，用它才能把窗口贴到桌面最底层、接管拖拽、读取真实文件图标 | 这是"桌面工具"绕不开的一层；我们用最少的必要调用，**不做注入**（注入＝硬闯别人程序内部，容易被杀软报毒、系统一更新就废） |
| **独立子进程** | 把"读缩略图、抽大文件图标"这种又慢又容易崩的活，交给一个**小助手程序**去做 | 小助手崩了，主程序毫发无伤，界面不卡 |

### 2.3 四层结构（每层干什么活）

```
┌─ 装修层：DeskNest.App（界面）
│  盒子的外观、设置窗口、搜索面板、桌宠、托盘图标……
│  只用"看"和"点"，不做任何重活（这是性能的关键）
├─ 承重墙：DeskNest.Core（逻辑与数据）
│  整理规则怎么判断、文件怎么搬、撤销怎么回滚、搜索怎么索引、
│  备份怎么做、统计怎么算 —— 全部不依赖界面，能单独测试
├─ 水电层：DeskNest.Native（和 Windows 打交道）
│  把窗口贴到桌面底层、接收拖拽、取文件图标、注册全局热键、
│  读取前台窗口（使用统计用）、执行关机命令
└─ 地基：SQLite 文件 + 配置文件（放 %LocalAppData%\DeskNest\）
```

**为什么这么分**：装修层永远不能干重活（一干重活界面就卡）；承重墙不依赖装修层，所以将来你想换成别的界面风格，逻辑一行都不用改；水电层是唯一碰系统的地方，将来 Windows 升级出问题，改一行就知道去哪找。

### 2.4 关键名词，一次讲清

| 术语 | 大白话 |
| --- | --- |
| 进程 / 子进程 | 一个正在运行的程序＝进程；子进程＝它再开的小程序（我们用它做"重活隔离"） |
| 线程 / UI 线程 | 程序里同时干活的"手"；只有一只手（UI 线程）能改界面，所以搬文件这种事绝不能占用它 |
| 异步 | "先答应、稍后给结果"：界面点一下立刻有反应，实际搬文件在后台进行 |
| 全局热键 | 在任何程序里都能生效的快捷键（比如 Alt+Space 唤出搜索） |
| 桌面层窗口 | 贴在壁纸之上、图标之下那一层的窗口，所以我们做的盒子"看起来长在桌面上" |
| 拖放 / IDropTarget | 让窗口能接收"把文件拖进来"这个动作的接口 |
| 数据库事务 | 一组操作要么全成功、要么全不算（避免搬一半文件就断电） |
| 整理"计划/执行"分离 | 先算出一份"要搬哪些文件、搬到哪"的清单给你看，你确认了再真的搬 —— 这样才能做预览和撤销 |
| 索引 | 预先给所有文件建一份"电话簿"，搜索时不用现场翻盘 |

### 2.5 一次"拖文件进盒子"到底发生了什么（全流程示例）

1. 你把文件拖到盒子上 → 界面层捕获到"有东西被放下"。
2. 界面层立刻回复"收到"，**并马上松手**（保持界面流畅）。
3. 它在"待办清单"里写一条**意图记录**："要把 A 从桌面搬到盒子的存储目录"（写进数据库，断电也不丢）。
4. 水电层开始搬：同一个盘用"改名"（瞬间完成），跨盘用"复制+核对+删原件"。
5. 搬到一半失败？逐项报错，成功的保留、失败的回到原位，数据库记录同步更新。
6. 逻辑层广播"这个盒子的内容变了" → 界面层刷新这一个盒子（不动别的盒子）。
7. 你在 10 秒内按 Ctrl+Z：按意图记录反向搬回去，一字不差。

**为什么值得讲这么细**：整理类软件出一次"文件丢了"的事故，用户就再也不用了。上面这套"写意图 → 搬 → 核对 → 可回滚"的流程，是我们相对竞品最硬的地方。

### 2.6 可选模块是怎么做到"装了才有、不装不占地方"的

每个可选功能（使用统计、性能监视、API 面板、计划关机、截图录屏、AI 接口）都做成一个**独立小项目**，编译成单独的 `.dll`。程序启动时只扫描 `modules` 文件夹里"已经装了的"，没装的功能在界面上**显示为灰色 + 一句说明**（或干脆隐藏，由你选）。
好处：不装的功能**一行代码都不运行、一点内存都不占**；将来某个模块出 bug，最多停用它，主程序照常。

### 3.1 DeskBox 1.5.7（A 级）——本轮补充

上一版已拿到它的全部配置项（`settings.json`，schemaVersion 14）、组件布局结构（`widget-layout.json`）、运行日志与安装清单。本轮补充了三点：

1. **界面文案拿不到**：`DeskBox.exe`（51 MB）做 UTF-16 明文扫描，中文命中 **0**；`DeskBox.pri`（2.77 MB 的资源索引）同样 **0**。结论：WinUI 3 把字符串编译进了 PRI/XBF 二进制结构（不是简单压缩），要拿到措辞只能**运行时观察**（截图/UIA）或写一个 PRI 解析器。→ 对我们的意义：**我们自己的产品文案一律走外置资源文件（json/resx）**，方便改、也方便将来多语言，不用学它这种"编译死"的做法。
2. **它的性能策略是可抄的默认值**：隐藏后 30 秒清可重建缓存、可见空闲 600 秒修剪工作集、瞬态窗口 600 秒释放 —— 我们直接采用为默认值。
3. **它没有桌宠、没有使用统计、没有 AI 接口** —— 这三块是我们的差异化空间。

对我们的直接启示：① 待办/AI 待办/周报/倒计时/日历 是一套被验证过的组合，我们做"助手型桌宠 + 待办"时要覆盖这些场景；② 它的 AI 是**云端中转 + 强制登录**，我们做**本地直连各家 API + 用户自己的 Key**，更符合"数据和密钥都归你"的定位；③ 搜索位带广告是它的商业来源之一，**我们不这么做**。

### 3.5 REA 工具链实测记录（本轮）

- 环境：`rea` CLI 6.5.0 可用；`rea --help` 报告 **155 个命令**；Ghidra 12.1.4 在位；**JAVA_HOME 指到 JDK 17 时 Ghidra provider 不可用**，本机 `E:\RJ\jdk-21.0.12.1+1` 换成 21 后可用（Temurin 21.0.12.1）。REA 必须在**沙箱外**运行（沙箱内无法访问用户目录会报 `capability_unavailable`）。
- 成功的用法：`rea inspect-pe-resources <exe> --json` 用于 PE 资源身份/图标组/载荷范围。
- **踩到的限制**：对 360 的安装器，REA 直接拒绝解析 —— 报 `RT_GROUP_ICON length does not match its image count`（它的图标资源是畸形的，REA 做了严格校验）。→ 结论：**遇到畸形/非常规安装器，REA 会保守失败，此时靠"签名扫描 + 手工剥壳"更快**（我们这次就是这么拿到 14 MB 真实负载的）。
- 另一条已验证限制（上一轮）：对加密资源包（`XZDesktopRes.zip` 这类），REA 只能给**条目级清单**，拿不到内容 —— 与本次实测一致。
- 留给下一轮的：DeskBox 的 `.pri` 文案（需要运行时观察）、小智桌面加密包的真实文案（需要运行时观察或写解密器）。

## 7. 测试策略（闭环测试：发现问题→修复→再验）

### 7.1 四层测试

| 层 | 怎么做 | 覆盖重点 |
| --- | --- | --- |
| **单元测试**（xUnit） | 每个逻辑函数独立测 | **文件安全**（重名、跨卷、路径越界、还原失败、断电模拟）、整理规则判定、撤销幂等、位置/锚点换算、统计会话归并、关机时间计算 |
| **集成测试** | 真开临时目录跑完整流程 | 拖入→移动→撤销→还原；一键整理→历史回滚；备份→恢复；数据库迁移 |
| **冒烟测试清单**（手工，逐条勾） | 每次构建后照单子跑一遍 | 见 7.2 |
| **性能回归** | 内置性能面板读指标，与上次基线对比 | 空闲 CPU/内存、热键延迟、组件切换落定、10 万条索引下的搜索延迟、拖入 200 个文件时 UI 线程停顿（< 100 ms） |

### 7.2 冒烟清单（v1.0 定稿版）

1. 冷启动 → 托盘出现 → 空闲 60 秒后 CPU ≈ 0、内存记录一次。
2. 桌面拖入 20 个文件进盒 → 全部到位、无重名覆盖。
3. 撤销 → 文件全部回到原位置（含原图标排序）。
4. 一键整理向导：预览数量 == 实际移动数量；未匹配项按设定处理。
5. 全盘搜索：输入 3 个字符 → 结果 < 200 ms 出现；打开/定位正确。
6. 全局热键：唤出搜索、一键隐藏全部桌面层；连按 10 次无异常。
7. 组件：6 类各添加一次，缩放/透明度/独立样式生效；组件组滚轮切换。
8. 胶囊模式：收起/展开/拖排序；重启后位置一致。
9. 桌宠：开启→打字跟随→点击反应→待办提醒气泡→关闭后完全不占内存。
10. 可选模块：逐个启用/停用/卸载，界面与内存占用随之变化。
11. 计划关机：设 3 分钟后关机 → 提前 1 分钟弹窗 → 点"取消" → 未关机。
12. 备份：手动备份 → 改数据 → 回滚 → 数据一致。
13. 卸载：卸载后无残留文件、无残留注册表项、桌面文件未被破坏。
14. 异常：强杀进程 → 重启后数据一致、意图记录被正确续做或回滚。

### 7.3 闭环纪律

每次改动 → 单元测试全绿 → 装一份（或跑便携版）→ 跑冒烟清单 → 记录问题 → 修复 → **重跑同一条清单**（不许只验改的那一条）→ 记进 `docs/CHANGELOG.md` 并在 GitHub 打 tag。

**决策**：桌宠引擎**自研**（.NET 10 + WPF 透明分层窗口 + 自绘动画），只从 VPet 学"状态机与插件化"、从 BongoCat 学"键盘跟随的手感与素材切换"；**不复制任何 GPL/AGPL 项目代码**，也不直接采用其美术素材。

### 9.2 引擎设计

```
PetEngine（逻辑，不碰界面）
  ├ 状态机：idle / typing / click / drag / sleep / think / happy / tired / remind
  ├ 输入源：键盘事件（默认关，只取"有按键"事实）、鼠标悬停/点击/拖拽、
  │         待办到点、番茄钟结束、系统状态（CPU/内存/网络阈值）、空闲计时
  ├ 表情与动作调度：优先级（提醒 > 点击 > 打字 > 空闲）+ 冷却时间（防抖）
  └ 插件点（可选）：第三方可注册新的触发源与动作
PetWindow（界面，透明分层窗口，只重绘脏区）
  ├ 素材包（.petpack）：清单 + 序列帧/APNG/GIF + 状态映射 + 授权信息
  ├ 尺寸/透明度/层级策略（总在最前 / 贴桌面层 / 空闲才出现）
  └ 气泡（提醒、问答、番茄钟）
```

### 9.3 助手型行为（全部可单独关）

| 行为 | 触发 | 表现 | 默认 |
| --- | --- | --- | --- |
| 待办提醒 | 待办到点 | 举手 + 气泡（可直接打勾完成 / 稍后 10 分钟） | 开 |
| 番茄钟 | 你启动专注 | 陪你坐好、到点鼓掌；结束 5 分钟提醒起身 | 开 |
| 久坐提醒 | 连续使用 50 分钟 | 伸懒腰 + 提示 | 开 |
| 饮水/休息 | 每 2 小时 | 举杯动画 | 关 |
| 系统状态 | CPU > 85% 持续 3 分钟 | 变"累"表情 + 提示关闭占资源的程序（可点开性能面板） | 开 |
| 电量/网络 | 笔记本低电量 / 断网 | 表情 + 提示 | 开 |
| 打字陪伴 | 你打字时 | 跟随敲击动作 | **关**（隐私敏感，需你手动开） |
| AI 问答 | 你说"问我一句" | 头顶"思考中"，气泡显示回答（可引用你的待办与文件元数据） | 关 |
| 空闲 | 10 分钟无输入 | 打瞌睡（可关） | 开 |

### 9.4 性能与省电

默认上限 30 FPS（可选 15/30/60）；窗口不可见或全屏应用在前台时降到 5 FPS 或暂停；素材按需解码 + LRU 缓存（单包上限 64 MB）；键盘事件合并 ≥ 50 ms；"直播模式"一键隐藏所有盒与组件只留桌宠。

### 9.5 素材与授权

`.petpack` 清单里**必须**有 `license` 字段；导入时展示"授权：CC-BY-NC / 自绘 / 未知"；未知授权的包给出提示并默认不启用。官方随包提供 1–2 个自绘基础形象（避免"免费版没表情"那种做法）；**不使用未授权的商业 IP 角色素材**。

## 10. 安装包自动分析与逆向流水线（你要求的"自动下载安装包、只逆向不安装"）

### 10.1 为什么要流水线

参考竞品会一直更新（DeskBox 1.5.7、小智桌面 4.1.6.12、360 桌面 11.0 都是 2026 年的版本）。手工剥壳一次可以，长期要靠脚本，而且必须**保证"只分析、不执行"**。

### 10.2 流水线设计（放在 `tools/installer-lab/`，不进主程序）

```
① 清单          tools/installer-lab/targets.json
                每项：名称 / 官方下载地址 / 版本 / 镜像与备用地址
② 下载          download.ps1：经代理下载到 _re\pkg\<名称>\<版本>\
                记录 URL、下载时间、字节数、SHA-256、数字签名
③ 只读识别      识别类型：PE / Inno Setup / NSIS / MSI / CAB / 7z 壳 / Electron(asar)…
                ⚠️ 全程只读取字节，绝不执行（脚本里对 .exe 只做解析，不调用 Start-Process）
④ 剥壳          innoextract（Inno）/ expand（CAB）/ 7z（7z 壳、NSIS）/ 手工签名扫描兜底
⑤ 清单化        输出：文件树、大小、版本信息、PE 资源、签名、字符串命中
⑥ 结论         自动生成 Markdown 报告：新增模块、新增开关、移除项、值得学的点
⑦ 归档          报告 + 原始包哈希 → 写入 _re\reports\<名称>-<版本>.md（可追溯）
```

### 10.3 安全约束（写进脚本注释与 README）

1. **只分析、不安装、不运行**：任何 `Start-Process` / `& <下载的 exe>` 都禁止；代码审查时重点看这一点。
2. 分析在**独立目录**进行，产物不进入安装目录。
3. 360 等含推广/统计模块的安装包，**永不安装**（本轮已确认其中含 `FolderPromotion.exe` 与 `360DeskAna.exe`）。
4. 下载地址只用官方 CDN；不下载/不使用"绿色破解版"。
5. 每次分析记录哈希，便于判断竞品是否偷偷更新。

### 10.4 本轮已按这套流程跑通一次

360 桌面精简版：下载（官方 CDN）→ 签名扫描（发现 PE 壳 + CAB + 7z 三层）→ `expand` 解 CAB → 7z 解 14 MB 负载 → 58 个文件清单 → 模块归类（主程序/服务/DeskBand/预览/推广/统计）→ 结论（见第 3.4 节）。全程未运行任何 360 程序。

## 12. 合规与风险

| 风险 | 对策 |
| --- | --- |
| 抄竞品代码/素材 | 只借鉴设计思路；WitchDrawer（非商业许可）、ZenDesktop（GPL-3.0）、VPet/BongoCat（Apache 可参考但自己重写）、AGPL 项目只看不抄；第三方依赖走 NuGet 并在"关于"页列许可 |
| 文件误删/错位 | 意图记录 + 完整移动清单 + 幂等回滚 + 大量单元测试（这是测试投入最大的模块） |
| 杀软误报 | 不注入、不挂钩用户进程、不使用键盘钩子做默认功能（打字跟随默认关）、可选代码签名 |
| 隐私 | 键盘只取"有事件"事实、不记录字符；不截屏；使用统计可"只记进程名"；诊断包默认脱敏；AI 接口默认只监听 127.0.0.1 且需 token |
| 关机误执行 | 三重保护：提前弹窗、可顺延、检测到大文件读写或网络传输时自动顺延；并提供"取消关机" |
| 全盘索引吃资源 | USN 日志增量索引（不反复遍历目录）+ 索引期间限速 + 可暂停；非 NTFS 盘退化为可配置的定时扫描 |
| Windows 更新导致桌面层失效 | 桌面层逻辑集中在 `Native` 小模块；提供"降级为普通置顶窗口"的兜底开关 |
