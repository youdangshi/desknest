### 2. 具体改了什么

| 改动 | 说明 |
| --- | --- |
| **行式设置** | 新增 `UiKit.Section / Row / Toggle / ToggleRow / ComboRow / SliderRow / InputRow / ActionRow / NavRow`：一行＝图标 + 标题 + 说明 + 右侧控件；行间自动加分隔线；整组套在圆角卡片里 |
| **开关样式** | 换成 iOS 风格的滑动开关（点击即时生效，不需要"保存"按钮） |
| **左侧导航** | 每项带图标（🏠🗂🧹🧩🖼🐾🎨🔌💾ℹ），选中态用强调色淡底 + 半粗字 |
| **顶部栏** | 中间是设置搜索框（输入"开机/透明度/统计/热键/桌宠/出图"可直接跳页），右侧是快捷搜索与一键整理 |
| **页面标题** | 大标题 + 一句说明（26 px），和 DeskBox 的「常规」页一致 |
| **留白与层级** | 页面内边距 28、卡片间距 16、行内边距 10/9，避免"挤在一起" |
| **清爽原则** | 主窗口只放"能一眼看懂"的开关；能就地完成的操作（盒子菜单、组件菜单）不进主窗口 |

### 3. 两级样式（保留你的要求）

- 全局样式：配色 / 材质 / 材质强度 / 默认透明度 / 圆角 / 减少动效
- 单个对象：每个盒子与组件都能选「跟随全局」或「单独设置」，并各自调透明度、圆角、材质、图标大小
- 一键操作：`把所有盒子与组件统一成全局样式` / `全部改为各自独立样式`

## 二、本地 ComfyUI 出图

### 1. 为什么这么做

你本机已经有完整的 ComfyUI 环境（绘世启动器 + 模型）。与其在桌巢里塞一个"云端画图"，不如**直接驱动你本机的 ComfyUI**：模型是你的、显存是你的、图片落在你硬盘上，不产生任何云端上传。

### 2. 能力

| 能力 | 说明 |
| --- | --- |
| 连接检测 | `GET /system_stats`，显示 ComfyUI 版本；连不上给明确提示 |
| 读取模型 | `GET /object_info/CheckpointLoaderSimple` → 下拉选择 checkpoint |
| 出图 | 内置文生图节点图（CheckpointLoaderSimple → CLIPTextEncode×2 → KSampler → VAEDecode → SaveImage），提交到 `POST /prompt` |
| 参数 | 尺寸（含 512/1024 快捷按钮）、步数、CFG（滑杆）、采样器、种子（留空随机）、一次出几张（1–8） |
| 等待结果 | 轮询 `GET /history/{prompt_id}`，界面上实时显示"等待出图…N 秒" |
| 保存 | `GET /view` 下载图片 → 存到 `图片\DeskNest 出图`（可在设置里改目录） |
| 结果画廊 | 最近 12 张缩略图；点击打开，右键可复制路径 / 设为桌宠形象 / 删除 |
| 联动 | 开关「出图后自动放进第一个收纳盒」：在盒子里建 `AI 出图` 子文件夹并登记条目 |

### 3. 为什么用"内置工作流 + 未来支持导入"

内置节点图的好处是**零配置**：只要 ComfyUI 在跑、有模型，点一下就能出图。
高级玩法（自己搭的复杂工作流）后续会支持导入 **API 格式** 的 workflow JSON；UI 格式的 workflow 需要先在 ComfyUI 里"导出 API 格式"，界面上会说明。

### 4. 与其它模块的关系

出图模块是**可选模块**（`DeskNest.Module.ComfyUI.dll`）：不装就没有这个页面，也不占内存；装了默认关闭，需要时在「模块」页打开。
