# 冒烟清单（每次发布前逐条过）

1. [ ] 冷启动：托盘出现、日志有「桌巢启动」、无异常退出
2. [ ] 空闲 60 秒：CPU 接近 0，内存记录一次基线
3. [ ] 新建收纳盒（桌面分区）：桌面文件被分类进盒，桌面变干净
4. [ ] 撤销条点「撤销」：文件全部回原位
5. [ ] 新建（文件夹归集）：桌面按类型建文件夹
6. [ ] 拖 20 个文件进盒子：全部到位、无覆盖
7. [ ] 盒内右键 → 删除：文件回到原位置；10 秒内点「撤销」能回到盒里
8. [ ] `Alt+Space`：搜索面板 < 200 ms 出现；输入 3 个字符有结果；Enter 打开
9. [ ] `Alt+``：桌面层显示/隐藏；再按一次恢复
10. [ ] 双击桌面空白：桌面图标切换（设置里可关闭）
11. [ ] 组件：六类各加一次，能缩放、能改透明度、能删除
12. [ ] 组件组：两个盒合并，标题栏切换与滚轮切换都生效；解散后恢复
13. [ ] 桌宠：启用后打字跟随（需手动开）、点击有反应、待办到点举手、关闭后进程无残留占用
14. [ ] AI 出图：ComfyUI 未启动时给出友好提示；启动后能读模型、出图、保存、右键设为桌宠形象
15. [ ] 模块开关：逐个启用/停用，界面与内存占用同步变化
16. [ ] 使用统计：开启后能看到今天各应用时长
17. [ ] 性能面板：读数刷新；GPU 无驱动时显示"需 NVIDIA 驱动"
18. [ ] API 面板：加一个 Key → 打码显示 → 测试调用有结果
19. [ ] 计划关机：设 3 分钟后关机 → 提前提醒 → 点取消 → 未关机
20. [ ] 备份：立即备份 → 改数据 → 回滚 → 数据一致
21. [ ] 强杀进程后重启：数据一致、意图记录被正确续做或回滚
22. [ ] 卸载：无残留文件与注册表项；桌面文件未被破坏
