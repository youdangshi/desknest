## 0. 读法约定

| 记号 | 意思 |
| --- | --- |
| ▸ | 二级菜单（悬停 200ms 展开） |
| ✓ | 勾选态 = 当前值 |
| （置灰） | 不可用，鼠标悬停给出**原因提示** |
| ⚠ | 危险操作（红色） |
| 值 | 括号里是存进配置的真实值 |

**通用交互规则（全应用统一）**

1. 按钮点击后 100ms 内有反馈（按下态变暗 10%），长任务显示"正在…"并禁用按钮。
2. 任何改动**立即生效并落盘**，没有"保存"按钮（除弹窗里的表单）。
3. 任何失败都**给一句人话**说明原因，不弹裸异常。
4. 弹窗：有 ✕、Esc 关闭、点遮罩不关闭（防误触）、Enter = 主按钮。
5. 所有下拉用同一套样式的**自绘弹出列表**（不用系统默认下拉），高 32/项、选中打勾。

### 1.5 全局热键（隐藏/显示所有盒子）

| 项 | 说明 |
| --- | --- |
| 默认热键 | **Ctrl + Alt + H** |
| 作用 | 桌面上**所有**盒子一起隐藏 / 恢复（不是单个） |
| 三处入口同一状态 | 热键 / 托盘左键 / 右键菜单「显示·隐藏 桌面盒」共用 `layerVisible`，任何一处改，另外两处立刻反映 |
| 修改 | 设置里点「修改」→ 录制态"请按下组合键…" → 按下即生效；Esc 取消 |
| 校验 | 必须含 Ctrl/Alt/Win 之一；不允许单键；被占用 → 提示"这个组合键被占用了"且**保留原热键** |
| 关闭 | 开关关掉 = 注销热键，完全无反应 |
| 落盘 | `hotkey.toggleBoxes`（"Ctrl+Alt+H"；空 = 关闭） |
| 提示文案 | 隐藏时：热键开着 → "盒子已隐藏，Ctrl+Alt+H 可恢复"；热键关了 → "盒子已隐藏，单击托盘图标可恢复" |

## 2. 页面：概览

### 2.1 结构

```
概览
桌面上的收纳情况，一眼看完。

[ 收纳盒 3 个 ]  [ 已收纳 47 项 · 12.4 MB ]  [ 托盘：常驻运行中 ]

[＋ 新建收纳盒]   [📂 打开数据目录]

快捷操作
  隐藏 / 显示所有盒子    [ Ctrl+Alt+H ]   [修改]   [✓ 启用]
```

### 2.2 每个控件

| 控件 | 数据来源 | 点击后 |
| --- | --- | --- |
| 统计卡「收纳盒 N 个」 | `Repo.Boxes().Count` | 跳到「收纳盒」页 |
| 统计卡「已收纳 N 项 · X MB」 | `Repo.Items()` 汇总 | 打开数据目录 |
| 统计卡「托盘状态」 | 运行中 / 已暂停 | 无操作（纯展示） |
| ＋ 新建收纳盒 | — | 弹「新建收纳盒」弹窗（见 §6.1） |
| 📂 打开数据目录 | `AppPaths.DataRoot` | 资源管理器打开；打不开→提示路径并复制到剪贴板 |

### 2.3 状态

| 状态 | 显示 |
| --- | --- |
| 一个盒子都没有 | 统计卡显示 0；下方出现引导块："桌面上的文件还没地方放？先建一个盒子" + 主按钮 |
| 有盒子但全隐藏 | 统计卡正常 + 一行小字"3 个盒子当前是隐藏的，点托盘图标可恢复" |
| 数据目录不存在 | 统计卡正常；打开按钮置灰 + 提示"数据目录还没创建" |

## 5. 页面：数据与备份 / 关于

### 5.1 数据与备份

| 控件 | 行为 | 状态/异常 |
| --- | --- | --- |
| 立即备份 | 生成 `backups\2026-10-17_1045\`（设置+数据库+盒子清单） | 进行中禁用并显示进度；失败给原因（磁盘满/无权限） |

| 生成诊断包 | 打包设置(去掉密钥)+日志+版本 → `desknest-diag-时间.zip` | 完成后提示路径并"复制路径" |
| 数据用量 | 显示 `DataRoot` 与占用大小 | 每 5 秒刷新（只在页面上） |

### 5.2 关于

| 控件 | 行为 |
| --- | --- |
| 版本号 | 读 csproj `<Version>`，只读 |
| 检查更新 | 点击 → "检查中…" → 三态：**已是最新** / **发现 vX.Y.Z（更新说明 / 打开下载页）** / **失败**（一句人话：网络不通 / 被限流，可重试） |

## 6. 弹窗清单（每个字段都写清）

### 6.1 新建收纳盒

```
┌─ 新建收纳盒 ─────────────────────────────── ✕ ┐
│ 名称      [ 新收纳盒                    ]      │
│ 类型      (•) 普通盒  ( ) 映射盒               │
│   ↳ 说明：普通盒会把文件真正移进盒子；         │
│          映射盒只登记路径，不动原文件。         │
│ 存储位置  [ C:\Users\李\DeskNest\新收纳盒 ] [选择…] │
│ （映射盒时此行换成）                           │
│ 映射路径  [ 选择文件夹…                      ]  │
│ ─────────────────────────────────────────────  │
│ 提示：不会自动搬走桌面上的任何文件              │
│                              [取消] [创建空盒子]│
└────────────────────────────────────────────────┘
```

| 字段 | 规则 | 异常 |
| --- | --- | --- |
| 名称 | 1–40 字；不能含 `\\ / : * ? " < > |`；不能与已有盒子重名 | 失焦即校验，错误红字在下方 |
| 类型 | 单选，默认普通盒 | 切换时下方说明与第三行联动 |
| 存储位置 | 默认 `DataRoot\<名称>`；可改；必须可写 | 不可写→红字"这个目录不可写" |
| 映射路径 | 映射盒必填；目录必须存在 | 不存在→红字 + 禁用创建按钮 |
| 创建 | 只创建**空盒子**（绝不搬文件） | 创建后关闭弹窗 + 桌面出现盒子 + 概览卡片 +1 |

### 6.2 删除盒子（⚠）

```
┌─ 删除收纳盒 ─────────────────────────────── ✕ ┐
│ 盒子「工作」里有 23 项文件。                    │
│ 删除后这些文件会**还原到原来的位置**；          │
│ 原位置不存在的会放到桌面。                      │
│                                                │
│ （映射盒只有一句）删除后只移除记录，不动文件。   │
│ [ ] 我明白，文件会从盒子里移走                  │
│                        [取消]  [删除 ⚠]        │
└────────────────────────────────────────────────┘
```

| 规则 | 说明 |
| --- | --- |
| 勾选后才能点删除 | 防误删 |
| 执行中 | 显示"还原中 3/23"，可取消（已还原的不回滚） |
| 失败单项 | 列出失败文件 + 原因，允许"重试 / 跳过" |
| 完成后 | 盒子消失，提示"23 个文件已还原（2 个放到了桌面）" |

### 6.3 单盒样式 —— 见 §3.2（同一个弹窗）

### 6.4 自定义颜色

```
┌─ 自定义颜色 ───────────────────────── ✕ ┐
│  [色相/饱和度面板]   [亮度条]           │
│  预览 ▉▉▉                               │
```

每项都可键盘走（↑↓/→进入/←返回/Enter 确认/Esc 全关）；长菜单自动滚动。

**标题栏按钮**（4 个，22×22）：＋ 添加文件（打开选择框）· ⋯ 打开右键菜单 · ⌄ 卷起/展开 · ✕ 隐藏盒子。

| 悬停 | 显示完整文件名气泡（被截断时才有） |
| 文件丢失 | 图标变灰 + 右上角"!"，双击提示"文件已不在原位置，可在原位置找找" |

## 12. 修订：学完 DeskBox 之后的定稿版（**覆盖 §7 的菜单树**）

> 依据：2026-10-17 实机截图（DeskBox 的格子右键菜单全层级 + 4 个设置页）。
> 我们**不抄它的功能**（组合格子、胶囊模式、整理都在我们的下架名单里），只抄**它组织选项的方式**。

### 12.1 抄过来的 12 条（每条：DeskBox 怎么做 → 我们用在哪）

| # | DeskBox 的做法 | 我们用在哪 |
| --- | --- | --- |
| 1 | **每个子菜单第一项永远是「跟随默认（当前值）」**，把值写在括号里，如"跟随默认（并排显示）""跟随默认（开）" | 我们所有「更多操作」子菜单第一项都加「跟随全局（当前值）」 |
| 2 | **置灰项直接写出原因**：如「悬浮 · 格子组需要持续可见的标题栏」「隐藏 · …」 | 我们不能点的项也这样写：「锁定中不能缩放」直接挂在项后面 |
| 3 | **每个菜单项前面都有小图标**，右侧有 › 表示还有下一级 | 12 项全部配图标；三级用 › |
| 4 | **危险操作沉底、红色、单独一组**（关闭格子） | 「删除盒子」保持红色 + 分隔线隔开 |
| 5 | **把相关的散项收成一个分组**：锁定位置/锁定尺寸 → 「格子锁定 ▸」，并在组内附一行说明"锁定仅禁止拖动和调整大小；恢复位置、更换显示器时仍会移动" | 我们同样做「格子锁定 ▸」+ 这一句说明 |
| 6 | **开关类给三种状态**：跟随默认 / 开 / 关（而不是只有开/关） | 高度自适应、显示文件名、标题栏滚轮等都用"跟随全局 / 开 / 关" |
| 7 | **展开方式是一整组枚举**：始终展开 / 单击展开 / 悬停自动展开 / 向上展开 / 向下展开 / 恢复自动宽度（置灰） | 我们的「展开方式 ▸」照这个结构（v2.0 只做前 3 个） |
| 8 | **"移到显示器"直接列出型号和分辨率**：显示器 1 · F24G30Q · 主显示器 / 显示器 2 · 2160×1440 / 始终在主显示器 | 多显示器用户直接点名，不写"显示器 1/2" |
| 9 | **设置页每项 = 图标 + 标题 + 一句灰色说明 + 右侧控件**；能展开的项右侧有 ⌄，展开后子项缩进 | 我们的 5 个页面全部按这个三件套重排 |
| 10 | **设置页有面包屑标题**：「文件格子 › 文件显示」 | 我们的页标题改成「外观与主题 › 收纳窗口」这种二级形式 |
| 11 | **上下文警告条（黄色）**："当前在 C 盘，整理文件不会释放 C 盘空间。" | 我们也加："数据目录在 C 盘，收纳不会释放 C 盘空间" |
| 12 | **设置页顶部有搜索框 + 左侧可收起的导航**，且「已单独设置的格子：9 个没有跟随全局」这种汇总入口 | 我们有搜索框；补一条「已单独设置的盒子 N 个 ›」 |

### 12.3 菜单视觉规格（照抄 DeskBox 的量）

| 项 | 规格 |
| --- | --- |
| 行高 | **36**（比我们现在 30 高，手指更好点） |
| 左内边距 | 12；图标 16×16，图标与文字间距 10 |
| 字号 | **13.5**；三级同字号，不缩小 |
| 勾选标记 | 16×16，画在最左（占图标位） |
| 子菜单箭头 | 12，贴右，右内边距 10 |
| 分隔线 | 1px，前景 8%，上下各留 4 |
| 面板 | 圆角 10、前景 6% 描边、阴影 `0 12 32 rgba(0,0,0,.35)` |
| 宽度 | 自适应文字，最小 200、最大 320；子菜单最大 12 项，超出滚动 |
| 展开时机 | 悬停 **200ms**、键盘 → 立即 |
| 置灰项 | 前景 35%，**不可点但可悬停**（气泡或行内后缀给原因） |

### 12.4 设置页行规格（照抄 DeskBox 的三件套）

```
┌──────────────────────────────────────────────────────────┐
│ [图标20]  标题 14 半粗                       [ 控件 ]     │
│           说明 12 灰（一句话，讲清"开了会怎样"）           │
├──────────────────────────────────────────────────────────┤  ← 可展开项
│ [图标20]  标题 14                            [ 控件 ] ⌄  │
│           ↳ 子项（缩进 44）                     [ 控件 ]  │
└──────────────────────────────────────────────────────────┘
```

- 卡片：行高最小 **64**，内边距 16/10，卡片间距 4，圆角 6，1px 前景 8% 描边。
- 页标题：**28 半粗**；面包屑用「›」；小节标题 15 半粗 + 上间距 14。
- 黄色提示条：圆角 6，底 8% 琥珀，图标 16，文字 12.5。
- 汇总入口："已单独设置的盒子 3 个 ›"（点了列出是哪些、能一键恢复跟随全局）。
