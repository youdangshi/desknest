## 0. 读法约定

| 记号 | 意思 |
| --- | --- |
| ▸ | 二级菜单（悬停 200ms 展开） |
| ✓ | 勾选态 = 当前值 |
| （置灰） | 不可用，鼠标悬停给出**原因提示** |
| ⚠ | 危险操作（红色） |
| 值 | 括号里是存进配置的真实值 |

**通用交互规则（全应用统一）**

1. 按钮点击后 100ms 内有反馈（按下态变暗 10%），长任务显示"正在…"并禁用按钮。
2. 任何改动**立即生效并落盘**，没有"保存"按钮（除弹窗里的表单）。
3. 任何失败都**给一句人话**说明原因，不弹裸异常。
4. 弹窗：有 ✕、Esc 关闭、点遮罩不关闭（防误触）、Enter = 主按钮。
5. 所有下拉用同一套样式的**自绘弹出列表**（不用系统默认下拉），高 32/项、选中打勾。

## 2. 页面：概览

### 2.1 结构

```
概览
桌面上的收纳情况，一眼看完。

[ 收纳盒 3 个 ]  [ 已收纳 47 项 · 12.4 MB ]  [ 托盘：常驻运行中 ]

[＋ 新建收纳盒]   [📂 打开数据目录]
```

### 2.2 每个控件

| 控件 | 数据来源 | 点击后 |
| --- | --- | --- |
| 统计卡「收纳盒 N 个」 | `Repo.Boxes().Count` | 跳到「收纳盒」页 |
| 统计卡「已收纳 N 项 · X MB」 | `Repo.Items()` 汇总 | 打开数据目录 |
| 统计卡「托盘状态」 | 运行中 / 已暂停 | 无操作（纯展示） |
| ＋ 新建收纳盒 | — | 弹「新建收纳盒」弹窗（见 §6.1） |
| 📂 打开数据目录 | `AppPaths.DataRoot` | 资源管理器打开；打不开→提示路径并复制到剪贴板 |

### 2.3 状态

| 状态 | 显示 |
| --- | --- |
| 一个盒子都没有 | 统计卡显示 0；下方出现引导块："桌面上的文件还没地方放？先建一个盒子" + 主按钮 |
| 有盒子但全隐藏 | 统计卡正常 + 一行小字"3 个盒子当前是隐藏的，点托盘图标可恢复" |
| 数据目录不存在 | 统计卡正常；打开按钮置灰 + 提示"数据目录还没创建" |

## 4. 页面：外观与主题

### 4.1 两套令牌（设计窗口 / 收纳窗口），每套同样的 6 行

| 行 | 控件 | 选项（**每个值都列出来**） | 默认 |
| --- | --- | --- | --- |
| 配色 | 下拉 | **跟随系统**(FollowSystem) / **深色**(Dark) / **浅色**(Light) / **纯黑**(PureBlack) / **护眼**(EyeCare) | 跟随系统 |
| 卡片颜色 | 9 个色块 + 自定义 | 跟配色方案 / 深灰 #2B2B31 / 纯白 #FFFFFF / 浅灰 #E9E9EE / 米色 #F3E9D7 / 深蓝 #16233A / 墨绿 #14261E / 酒红 #2A1418 / 紫黑 #201A2E ／自定义（取色器 + 十六进制输入） | 跟配色方案 |
| 材质 | 下拉 | **亚克力**(Acrylic) / **云母**(Mica) / **纯色**(Solid) | 亚克力 |
| 材质强度 | 滑块 | 0.1 – 1.0，步进 0.05 | 0.65 |
| 默认透明度 | 滑块 | 0.25 – 1.0，步进 0.05 | 0.82 |
| 圆角 | 滑块 + 4 个点 | 0 / 6 / 12 / 18（可连续 0–28） | 12 |

> 「卡片颜色」**只在「收纳窗口」那套出现**；设计窗口那套没有这一项（它没有"卡片"这一层）。

### 4.2 行内交互

| 触发 | 行为 |
| --- | --- |
| 拖动滑块 | 实时预览（盒子当场变），松手落盘 |
| 滑块双击 | 回到默认值 |
| 下拉展开 | 列表项高 32，当前项打勾，支持 ↑↓ 选择、Enter 确认、Esc 关闭 |
| 选配色 | 整页重绘（设计窗口那套要重建页面） |
| 选材质 | 不重建，只重画 |

### 4.3 底部三个动作

| 按钮 | 行为 | 二次确认 |
| --- | --- | --- |
| 统一所有盒与组件 | 把所有盒子改成"跟随全局"，并把当前值写进每个盒子 | 是：「会把 3 个盒子的单独样式清掉，继续？」 |
| → 把设计窗口的复制给收纳窗口 | 复制 6 个值过去 | 否（有撤销提示） |
| ← 反向复制 | 同上 | 否 |

### 4.4 主窗口背景（独立小节）

| 控件 | 行为 |
| --- | --- |
| 开关「用不透明背景」 | 打开＝实色底 + 关毛玻璃；Win10 默认已打开 |

## 5. 页面：数据与备份 / 关于

### 5.1 数据与备份

| 控件 | 行为 | 状态/异常 |
| --- | --- | --- |
| 立即备份 | 生成 `backups\2026-10-17_1045\`（设置+数据库+盒子清单） | 进行中禁用并显示进度；失败给原因（磁盘满/无权限） |
| 从备份回滚 ▾ | 二级列表：每个备份一行（时间 + 大小 + "恢复"按钮） | 选旧版本→二次确认「会覆盖当前数据（会先自动备份一份现状）」 |
| 打开数据目录 | 资源管理器 | 路径不存在→先创建再打开 |
| 生成诊断包 | 打包设置(去掉密钥)+日志+版本 → `desknest-diag-时间.zip` | 完成后提示路径并"复制路径" |
| 数据用量 | 显示 `DataRoot` 与占用大小 | 每 5 秒刷新（只在页面上） |

### 5.2 关于

| 控件 | 行为 |
| --- | --- |
| 版本号 | 读 csproj `<Version>`，只读 |
| 检查更新 | 点击 → "检查中…" → 三态：**已是最新** / **发现 vX.Y.Z（更新说明 / 打开下载页）** / **失败**（一句人话：网络不通 / 被限流，可重试） |
| 自动检查（可选） | 开关，默认关；打开后启动时查一次，**不弹窗**，只在托盘气泡提示 |
| 开源许可 | 列出 WPF-UI / Meteocons / Fluent Emoji 等 + 许可名 |

## 6. 弹窗清单（每个字段都写清）

### 6.1 新建收纳盒

```
┌─ 新建收纳盒 ─────────────────────────────── ✕ ┐
│ 名称      [ 新收纳盒                    ]      │
│ 类型      (•) 普通盒  ( ) 映射盒               │
│   ↳ 说明：普通盒会把文件真正移进盒子；         │
│          映射盒只登记路径，不动原文件。         │
│ 存储位置  [ C:\Users\李\DeskNest\新收纳盒 ] [选择…] │
│ （映射盒时此行换成）                           │
│ 映射路径  [ 选择文件夹…                      ]  │
│ ─────────────────────────────────────────────  │
│ 提示：不会自动搬走桌面上的任何文件              │
│                              [取消] [创建空盒子]│
└────────────────────────────────────────────────┘
```

| 字段 | 规则 | 异常 |
| --- | --- | --- |
| 名称 | 1–40 字；不能含 `\\ / : * ? " < > |`；不能与已有盒子重名 | 失焦即校验，错误红字在下方 |
| 类型 | 单选，默认普通盒 | 切换时下方说明与第三行联动 |
| 存储位置 | 默认 `DataRoot\<名称>`；可改；必须可写 | 不可写→红字"这个目录不可写" |
| 映射路径 | 映射盒必填；目录必须存在 | 不存在→红字 + 禁用创建按钮 |
| 创建 | 只创建**空盒子**（绝不搬文件） | 创建后关闭弹窗 + 桌面出现盒子 + 概览卡片 +1 |

### 6.2 删除盒子（⚠）

```
┌─ 删除收纳盒 ─────────────────────────────── ✕ ┐
│ 盒子「工作」里有 23 项文件。                    │
│ 删除后这些文件会**还原到原来的位置**；          │
│ 原位置不存在的会放到桌面。                      │
│                                                │
│ （映射盒只有一句）删除后只移除记录，不动文件。   │
│ [ ] 我明白，文件会从盒子里移走                  │
│                        [取消]  [删除 ⚠]        │
└────────────────────────────────────────────────┘
```

| 规则 | 说明 |
| --- | --- |
| 勾选后才能点删除 | 防误删 |
| 执行中 | 显示"还原中 3/23"，可取消（已还原的不回滚） |
| 失败单项 | 列出失败文件 + 原因，允许"重试 / 跳过" |
| 完成后 | 盒子消失，提示"23 个文件已还原（2 个放到了桌面）" |

### 6.3 单盒样式 —— 见 §3.2（同一个弹窗）

### 6.4 自定义颜色

```
┌─ 自定义颜色 ───────────────────────── ✕ ┐
│  [色相/饱和度面板]   [亮度条]           │
│  预览 ▉▉▉                               │
│  十六进制 [ #4C8BF5 ]  [取屏幕颜色…]     │
│  对比度提示：白字 5.2:1 ✓ 黑字 4.0:1 ✗   │
│                        [取消]  [确定]    │
└─────────────────────────────────────────┘
```

- **对比度提示必须实时算**：低于 4.5:1 给黄字提醒（但我们仍会自动选合适的文字色，所以只是提示）。

### 6.5 通用确认框

```
┌─ 确认 ────────────────────── ✕ ┐
│ 一句话问题？                     │
│               [取消] [确定]      │
└─────────────────────────────────┘
```
Esc/取消 = 关闭；Enter = 确定（危险操作时 Enter 落在"取消"上）。

| `Enter` | 打开选中项 |
| `Ctrl+A` | 全选盒内条目 |
| `Esc` | 关菜单/弹窗/取消拖动 |
| `Tab` | 弹窗内焦点循环（不跑出弹窗） |

- 所有可点元素：键盘可达 + 悬停与焦点态一致（不靠颜色区分）。
- 动效 ≤ 200ms；系统"减少动画"时改为瞬时。
