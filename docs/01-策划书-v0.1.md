## 1. 一页纸结论（TL;DR）

**做什么**：Windows 10/11 上一个常驻的桌面增强工具，三块能力合一——
① **桌面整理**（收纳盒 / 映射盒 / 一键整理 / 规则整理 / 可撤销）；
② **桌面组件**（待办、随记、天气、音乐、系统监视、概览，且能**编组为标签页容器**、能**收成胶囊条**）；
③ **桌宠**（键盘跟随打字 + 表情状态机 + 素材包，这是四个竞品**都没有**的差异点）。

**不做什么**（写进红线，避免做成竞品那样）：
不弹会员广告、不做后台推广位、不注入 Explorer、不捆绑安装、不把基础整理功能阉割成付费墙、不在 UI 线程做磁盘 IO。

**技术路线（建议）**：**.NET 10 + WPF 三层（App/Core/Native）+ SQLite + 自研 Win32 互操作层**。
理由：WitchDrawer（A/B 级证据）已用这条路线把"桌面层窗口 + 拖放 + Shell 图标 + 热键"全部跑通，风险最低；WinUI 3（DeskBox 路线）材质更现代但桌面层要多写大量 COM 互操作、Win10 上部分效果受限；CEF（小智桌面路线）内存与启动成本高。

**性能预算（写进验收门）**：空闲 CPU < 1%、常驻内存 < 150 MB、热键到面板 < 200 ms、桌面盒拖拽不抢焦点、缩略图/图标抽取全部离开 UI 线程。

**里程碑**：M0 骨架 → M1 收纳盒 MVP → M2 搜索与一键整理 → M3 组件系统与胶囊模式 → M4 桌宠与主题/备份。详见第 10 节。

**要避**：安装包与配置强绑定单一托管目录（用户一旦想换盘要迁移）；设置项过多导致配置面板拥挤（它用了 8 页导航才装下）。

### 2.3 WitchDrawer 1.4.4（B 级，源码级公开）

定位与形态：**.NET 10 + WPF 原生**桌面文件收纳工具，三层结构 `WitchDrawer.App`（WPF/MVVM/拖放/热键接线）→ `WitchDrawer.Core`（模型、SQLite、搜索、文件安全操作）→ `WitchDrawer.Native`（Shell、全局热键、桌面集成）；数据在 `%LocalAppData%\WitchDrawer\`（`witchdrawer.db` + `Boxes\{BoxId}\` + `logs\`），支持 `WITCHDRAWER_DATA_DIR` 覆盖与目录迁移。

产品能力（README 原文归纳）：

1. **四种盒子**：普通盒（文件**实体移动**进数据目录）/ 映射盒（只存绝对路径）/ 抽屉盒（可展开面板）/ 待办盒（待办 + 归档 + 完成率）。
2. **快捷面板**：`Ctrl+Alt+W`，跨盒搜索（按名称/路径/盒名），键盘操作。
3. **严格的文件操作语义表**（最值得抄的一张表）：拖入=移动；粘贴=复制保留源文件；重命名=改存储实体名且还原时用新名；删除文件项/盒子=**把文件还原回原目录，原目录不存在则回退桌面**；重名自动 `name (1).ext`；映射盒只改引用、不跟踪源文件外部移动。
4. **桌面集成**：记忆盒子位置、卷起、自动隐藏、**隐藏桌面图标 + 双击桌面空白切换**、吸附对齐（`SnapGeometry`）、引导线（`GuideLineWindow`）、位置/尺寸锁、多显示器（`DesktopDisplayMessages`）、桌面层级监控（`DesktopLayerMonitor`）、非激活覆盖窗（`NonActivatingOverlayWindow`）、全局鼠标键监听。
5. **外观**：三套主题、透明度/颜色/圆角/图标大小可调、像素风格盒子、双语即时切换。
6. **日常运维**：托盘、开机自启、更新检查+自校验、诊断日志导出（不含数据库与用户文件）、数据目录迁移、崩溃恢复包采集脚本。

工程实践（`docs/ARCHITECTURE.md`）：启动创建目录 → 初始化 SQLite → 空库时建默认盒；文件移动优先同卷 rename，跨卷退化为 copy+delete；删除盒子要求逐项还原全部成功才删记录；`BoxChangeNotifier` 统一广播内容变更、多界面各自刷新；**UI 线程不得做文件 IO / SQLite 写 / 图标提取**；列表虚拟化必须开启；快捷面板目标 < 200 ms；**空闲 CPU 接近 0%、内存尽量 < 150 MB**；仓库里还有 `investigation/` 性能对比报告（弹窗延迟前后、启动耗时基线）、`UiThreadStallMonitor`、约 180 个测试文件。

许可证：**GNU GPL v3.0**（2026-10-17 核实；早先记为 PolyForm Noncommercial，已纠正），文档与素材 CC BY-NC-SA 4.0 —— **非商业许可，不能抄代码/素材、不能商用**，只能学设计思路。

### 2.4 ZenDesktop 4.1.0（B 级，源码级公开）

形态：**Windhawk 注入式 C++ mod × 6** + 独立 `ExplorerBlurMica`（资源管理器毛玻璃）。六个 mod：任务栏亚克力、通知中心/日历/快速设置亚克力、开始菜单亚克力（可调宽高、文件夹独立透明度）、**双击桌面空白隐藏/显示图标（带淡入淡出、重启后保持状态）**、设置应用亚克力、**macOS 网格变形最小化动画**（Direct2D，8–96 网格细分、支持自动隐藏任务栏唤出、进程排除、多显示器）。

做法特点：纯本地编译（`local@` 前缀）、`deploy.bat`/`deploy.ps1` 一键部署 + 清理旧 mod + 重置 UI 缓存、全中文命名的 mod 卡片、GPL-3.0、宣称"零后台进程、0% CPU"。

对我们的启示：**"双击桌面空白隐藏图标"已经是行业标配，必须做**；系统级视觉增强体验好，但注入 Explorer 的方案在 Windows 更新后极易失效、且有杀软误报风险 —— 我们的产品**不采用注入路线**，改为"自己的桌面层窗口 + 不注入"。

### 2.8 从逆向里得到的 10 条结论

1. **整理类工具的护城河是"文件安全"，不是 UI**：WitchDrawer 把"拖入=移动、粘贴=复制、删除=还原"写成规则表并配套重名策略/跨卷退化/还原失败保护 —— 我们必须先做这套内核再用 UI 包装。
2. **可撤销与历史记录是刚需**：DeskBox 有 `desktop-organization-history.json` + `.bak`，WitchDrawer 有 10 秒撤销。自动整理没有撤销，用户不敢开。
3. **性能即体验，且要可测量**：DeskBox 用 `prepare/firstFrame/settle` 三段埋点验收组件切换；WitchDrawer 直接把 CPU/内存写进架构文档。我们把预算写进验收门。
4. **缓存的"清理策略"要显式设计**：隐藏 30 秒清可重建缓存、可见空闲 600 秒修剪工作集、瞬态窗口 600 秒释放 —— 这三条直接照搬为默认值。
5. **组件组（一个位置放多个组件，滚轮/悬停切换）是 DeskBox 最聪明的设计**：桌面空间有限，编组等于"给桌面加了标签页"。
6. **胶囊/紧凑模式解决"组件占地方"**：收成一条悬浮胶囊条，点开展开，且收起态要单独记位置。
7. **位置记忆必须绑定显示器稳定 ID**，不能存绝对坐标（换个分辨率/插拔显示器就全乱）。
8. **热键要有看门狗**：被别的软件抢注册后能自动抢回。
9. **桌面层工具必然会与 Shell 扩展/注入类软件冲突**（小智用黑名单避让），我们的产品要"检测到冲突就降级 + 给用户明确的开关"，而不是硬碰。
10. **不做的东西同样要写进文档**：会员弹窗、桌面推广位、后台统计、注入 Explorer、捆绑 —— 这是用户信任的来源，也是我们和竞品拉开差距的地方。

## 3. 产品定位

### 3.1 一句话定位

> **把乱桌面变成一个"能自己收拾、能常驻有用信息、还有点好看"的桌面** —— 整理、组件、桌宠三合一，全程不打扰、不收费墙、不弹广告。

### 3.2 目标用户与场景

| 用户 | 场景 | 我们要满足的核心诉求 |
| --- | --- | --- |
| 主用户（你）：长期把项目、素材、快捷方式堆在桌面的重度使用者 | 桌面上十几类文件（AI 项目/建模/视频音乐/系统工具），找东西靠记忆 | 分区盒 + 全局搜索 + 自动整理规则 |
| 上班族 / 学生 | 桌面小、不想天天手动归位 | 一键整理 + 自动整理 + 撤销 |
| 内容创作者 / 主播 | 想要好看的桌面、录制时画面干净 | 桌宠 + 主题 + 组件（对直播友好，可一键隐藏组件） |
| 追求"系统美化"的玩家 | 喜欢 ZenDesktop/TranslucentTB 那类效果 | 亚克力材质、胶囊模式、双击隐藏图标 |

### 3.3 差异化（和四个竞品比，我们的三条硬差异）

1. **整理 + 组件 + 桌宠在同一套壳里**（其余竞品最多占两块，桌宠只有我们做）。
2. **零打扰的商业模式**：基础功能永久免费且完整；只有"素材包 / 云同步 / 高级主题"可选付费，**不做会员弹窗、不做推广位、不阉割整理功能**。
3. **一切可撤销 + 一切可开关**：整理有历史可回滚；每个动效、每个组件、每个热键都能单独关掉——把"性能洁癖"和"视觉自由"都照顾到。

### 3.5 范围边界

**做**：文件收纳与整理、全局搜索、桌面组件与组件组、胶囊模式、桌宠、主题与外观、备份/迁移、托盘与热键、引导。

## 5. 信息架构与数据模型

### 5.1 信息架构

```
桌宠（独立小窗）      桌面层（常驻）
  ├ 宠物×N             ├ 收纳盒×N（普通/映射/抽屉/待办）
  └ 设置               ├ 组件组×N ── 组件×M（文件/待办/随记/天气/音乐/系统监视/概览）
                       └ 胶囊条（收起的组/盒）

主窗口（管理台）
  ├ 概览（盒/组件/整理状态一览）
  ├ 收纳盒（列表、新建、导入、批量操作）
  ├ 组件（添加、编组、外观）
  ├ 整理（规则、历史、回滚、白名单）
  ├ 桌宠（素材包、行为、按键映射）
  ├ 外观（主题、材质、圆角、动效）
  ├ 数据（备份、迁移、导出）
  └ 关于（版本、日志、更新、许可）

托盘：显示/隐藏桌面层｜暂停自动整理｜打开主窗口｜快捷搜索｜设置｜退出
```

### 5.2 数据模型（SQLite，单库 + 少量 JSON）

```sql
-- 收纳盒
boxes(id, name, kind,            -- kind: normal | mapped | drawer | todo

      display_name, source_path,     -- 原始位置（用于还原）

      ext, size_bytes, mtime, added_at, is_favorite, tags_json, order_index,
      stack_key,                     -- 文件堆叠分组键
      is_missing)                    -- 映射源失效标记

-- 整理规则与历史
rules(id, name, enabled, priority, conditions_json, actions_json, created_at)
org_runs(id, started_at, finished_at, trigger,    -- manual | schedule | on_new_file
         moved_count, undone, snapshot_json)      -- 回滚所需的完整移动列表

-- 组件
widgets(id, kind, name, group_id, box_id,          -- 文件类组件可绑定盒
        monitor_key, anchor, margin_x, margin_y, width, height,

widget_groups(id, name, member_ids_json, active_member_id,
        nav_style, title_display_mode, wheel_switch, hover_switch,
        animation_style, chrome_mode,
        monitor_key, anchor, margin_x, margin_y, width, height, collapsed_pos_json)

-- 桌宠
pets(id, pack_id, name, scale, opacity, anchor, margin_x, margin_y,
     topmost_mode,          -- always | on_desktop | when_idle

     fps_limit, monitor_key, is_visible)
```

设计要点（都是竞品踩出来的）：

- **位置记忆一律"锚点 + 边距 + 显示器稳定 ID"**，不存绝对坐标（对齐 DeskBox 的 `positionAnchor/positionMargin*/positionMonitorStableId`）。
- **收起态单独存一份位置**（`collapsed_pos_json`）——否则展开/收起会互相覆盖。
- **整理历史存"移动清单"而不是存结果**：回滚时按清单反向移动，幂等且可审计。
- 配置双写：`settings.json` + `settings.json.bak`，损坏时自动回退上次可用版本。

## 6. UI 设计系统（所有界面的共同底座）

### 6.1 设计语言：把"安静"作为第一原则

桌面工具长期开着，所以设计目标是**不抢注意力**：低饱和、低对比、少描边、动效克制、信息分层靠留白而不是靠颜色。

### 6.2 设计令牌（Design Tokens）

| 令牌 | 取值 | 说明 |
| --- | --- | --- |
| 材质 | `Mica`（主窗口背景）/ `Acrylic`（桌面盒、组件、弹层）/ `Solid`（低配/开"省电"时） | 跟随系统"透明效果"开关；可全局降级为纯色 |
| 材质强度 | 0–100%，默认 65% | 对应 DeskBox 的 `widgetMaterialIntensity` |
| 圆角 | 4 / 8 / 12 / 16 px；默认 12（盒/组件）、8（按钮/输入框）、16（主窗口） | 全局可调 |
| 描边 | 1 px，前景色 8% 透明度（深色 12%） | 只做"边缘分离"，不做装饰 |
| 阴影 | 两层：0 2 8 rgba(0,0,0,.18) + 0 8 24 rgba(0,0,0,.12) | 胶囊/桌宠用第二层加强 |
| 背景色 | 深色 `#1B1B1F` / 浅色 `#F6F6F8`，跟随系统 | — |
| 前景色 | 深色 `#F5F5F5` / 浅色 `#1A1A1A`；次要文字 62%，禁用 40% | 对应 `widgetForegroundMode` |
| 强调色 | 跟随系统强调色；内置 8 色预设 | 只用于：选中、进度、桌宠高亮、拖拽落点 |
| 字号 | 11（辅助）/ 12（次要）/ 13（正文）/ 15（小标题）/ 20（页面标题） | 支持系统字体缩放 |
| 行高 | 1.4（列表）、1.35（标题） | — |
| 字体 | `Microsoft YaHei UI` → `Segoe UI Variable` → `思源黑体` | 数字用等宽变体避免跳动 |
| 间距 | 4 的倍数：4 / 8 / 12 / 16 / 24 | 盒内边距 10，组件内边距 12 |
| 图标 | 线性 1.5 px，尺寸 16 / 20 / 24；盒内文件图标 24–48 可调（默认 30） | 借鉴 DeskBox 的 30 px 默认值 |
| 动效时长 | 快 120 ms / 标准 200 ms / 慢 320 ms | 组件展开收起用"慢" |
| 缓动 | 标准 `cubic-bezier(0.2, 0, 0, 1)`；入场 `ease-out`；退场 `ease-in` | — |
| 减少动效 | 一个总开关：关掉后所有动画退化为淡入淡出 ≤ 100 ms | 无障碍必需 |

### 6.3 交互约定（全局）

- **拖拽**：拖动中盒子外框高亮 2 px 强调色；落点插入位置显示 2 px 竖线 + 半透明占位块；跨盒拖动时源盒项半透明 40%。
- **吸附**：盒/组件边缘距屏幕边缘或彼此 5 px 内自动吸附，显示 1 px 引导线（学 WitchDrawer 的 `GuideLineWindow`）。
- **右键**：桌面盒的空白处右键 = 盒子菜单；文件项右键 = 文件菜单（默认调用系统菜单，设置里可切回自绘菜单）。
- **双击**：文件项双击打开；桌面空白双击 = 切换桌面图标（可关）。
- **键盘**：`Esc` 关闭面板；`↑↓` 选项；`Enter` 打开；`F2` 重命名；`Delete` 删除（还原）；`Ctrl+Z` 撤销（10 秒内）。
- **焦点**：所有弹层打开时抢焦点还是"不抢焦点"要区分——**桌面盒/组件不抢焦点**（否则打断用户打字），**搜索面板/设置窗口抢焦点**。
- **空态**：每个界面都要有"空的时候长什么样"的设计（第 7 节逐屏给出）。
- **忙碌态**：任何超过 300 ms 的操作要显示进度（环形 + 文字 + 可取消），不阻塞界面。

### 6.4 无障碍与多语言

键盘全可达（Tab 顺序明确、焦点环 2 px 强调色）；对比度 ≥ 4.5:1（正文）；支持系统字体缩放 100–200%；中英双语资源分离（学 WitchDrawer/Witchcat 的 `Strings.resx` + `Strings.zh-CN.resx` 双文件）；日期/数字跟随区域设置。

**目标**：在桌面上提供一个"随取随用、不打扰"的文件容器。

**入口**：主窗口新建 / 桌面右键菜单"新建收纳盒" / 拖文件到桌面空白处出现"新建盒"投放区。

## 8. 桌宠模块专项设计（差异化核心）

### 8.1 目标与定位

参考截图那款 bongocat 桌宠的**爽点**（跟随打字、表情丰富、放桌面/直播好看），补上它的**短板**：

| 截图那款的短板 | 我们的做法 |
| --- | --- |
| 免费版"无表情"、动画锁在付费版 | **引擎与素材解耦**：核心引擎免费且功能完整；素材包自由导入，官方素材包免费提供基础款 |
| 只做键盘跟随 | 键盘跟随 + 鼠标互动 + **系统/日程联动**（CPU 高、待办到期、专注计时结束都有反应） |
| 素材与逻辑硬编码（换形象要换整个 app） | **`.petpack` 素材包**：一张清单 + 雪碧图/序列帧 + 状态机定义，拖进来即用 |
| 只面向 Windows 桌面 | 同样支持"置顶 / 贴桌面层 / 空闲才出现"三种层级策略，直播时画面干净 |

### 8.2 素材包格式（`.petpack`，本质是一个 zip）

```jsonc
// manifest.json
{
  "format": "petpack/1",
  "id": "aemeath-bongo",
  "name": "爱弥斯 bongocat",
  "author": "你 / 画师署名",
  "license": "CC-BY-NC-4.0",          // 必须写明，引擎会在"关于"页展示
  "canvas": { "width": 256, "height": 256, "scale": 1.0, "anchor": [0.5, 1.0] },
  "sprites": {
    "idle":   { "type": "apng", "file": "idle.apng", "fps": 12, "loop": true },
    "typing": { "type": "sheet", "file": "typing.png", "frame": [256,256], "fps": 24, "loop": true },
    "click":  { "type": "sheet", "file": "click.png",  "frame": [256,256], "fps": 18, "loop": false },
    "sad":    { "type": "apng", "file": "sad.apng",    "fps": 10, "loop": true }
  },
  "states": {
    "default": "idle",
    "onKeyPress": { "state": "typing", "holdMs": 420, "cooldownMs": 60 },
    "onClick":    { "state": "click",  "holdMs": 600 },
    "onHighCpu":  { "state": "sad",    "threshold": 85, "holdMs": 3000 }
  },
  "sounds": { "onClick": "click.wav" }          // 可选，默认关闭声音
}
```

引擎能力：APNG / PNG 序列帧 / GIF / WebP 动画，多套皮肤切换，支持"额外配件层"（例如戴帽子）。

### 8.3 输入与联动

| 触发源 | 默认行为 | 隐私与性能 |
| --- | --- | --- |
| 键盘按下 | 播放 typing / 高亮按键 | **默认关**；开启后仅在内存里取"有键按下"的事件，**不记录按键内容、不落盘、不联网**；可限定"仅本程序前台时" |
| 鼠标移动/点击/悬停 | 视线跟随（可用"眼动层"）、点击反应 | 仅使用本程序窗口范围内事件 |
| 拖拽宠物 | 跟手 + 随机抱怨动作 | — |
| 系统状态 | CPU/内存/网络阈值触发表情 | 复用系统监视组件的数据源 |
| 待办到期 | 举手/跳动 + 气泡提醒 | 与待办组件共享提醒 |
| 专注/番茄钟结束 | 鼓掌/挥手 | P2 与番茄钟组件一起 |
| 空闲 | 打瞌睡、随机小动作 | 空闲检测基于用户输入事件（本程序内） |

### 8.4 性能与省电

- 渲染：透明分层窗口 + 只重绘脏区；默认上限 30 FPS（可 15/30/60），非活动状态降到 5 FPS 或暂停。
- 内存：素材按需解码 + LRU 缓存，单素材包上限 64 MB。
- 触发：键盘联动用低级钩子时**必须**做节流（≥50 ms 合并），并允许用户关闭。
- 直播友好：一键"直播模式"= 隐藏所有盒/组件、只保留桌宠 + 锁定位置 + 关闭动画抖动。

### 8.5 桌宠相关界面

- **桌宠设置页**（主窗口 → 桌宠）：素材包列表（封面 + 名称 + 授权 + 大小 + 已装/可更新）、导入按钮（拖入 .petpack / 选择文件）、当前宠物预览区（可试播所有状态）、行为开关（键盘/点击/系统/待办/空闲）、尺寸与透明度、层级策略、FPS 上限、声音开关、删除素材包（含"同时删除缓存"）。
- **导入向导**：选择素材包 → 显示清单与授权 → 预览 idle/click/typing → 选择是否应用 → 完成。
- **授权提示**：素材包 license 字段缺失时提示"该素材包未声明授权，请确认你有权使用"，把责任前移。

> 素材来源建议：自绘 / 委托画师 / 采用明确允许商用的开源素材；**不要**直接使用商业 IP 角色素材（截图里那种"鸣潮·爱弥斯"同人周边只能个人自用，不能随产品分发）。

## 9. 技术架构与实现要点

### 9.1 选型对比

| 方案 | 代表 | 优点 | 风险/成本 | 结论 |
| --- | --- | --- | --- | --- |
| **.NET 10 + WPF** | WitchDrawer（A/B 级证据） | 桌面层窗口/拖放/Shell/热键全都有现成成熟做法；C# 迭代快；自包含发布免装运行时；测试体系好写（它有 ~180 个测试文件） | 材质效果需自己做 Mica/Acrylic（可用 DWM 接口 + 自绘） | ✅ **推荐** |
| WinUI 3 / WinAppSDK | DeskBox | 原生材质、动画最正统 | 桌面层"非激活窗口 + 穿透 + 拖放"要写大量 COM 互操作；Win10 支持受限；`.pri` 资源链复杂 | 备选（若你更看重现代材质） |
| Tauri / Electron（CEF） | 小智桌面（CEF） | UI 迭代最自由 | 内存与启动成本高（CEF 光 `libcef.dll` 就 123 MB）；与"轻量常驻"目标冲突 | ❌ |
| Windhawk 注入 | ZenDesktop | 系统级效果最彻底 | Windows 更新即失效、杀软误报、崩溃影响 Explorer | ❌ 不注入 |

### 9.2 分层与目录（建议）

```
desktop-organizer/
├── src/
│   ├── DeskNest.App/          # WPF 外壳：主窗口、桌面宿主、组件、桌宠、托盘、设置
│   │   ├── Views/             # 每个界面一个 View（对应第 7 节的 S1–S15）
│   │   ├── ViewModels/        # MVVM，按功能域拆分（Boxes/Widgets/Pets/Organize/Settings）
│   │   ├── Infrastructure/    # 主题、动效、DPI、焦点、虚拟化列表
│   │   └── Resources/         # 字符串资源（中/英）、图标、皮肤
│   ├── DeskNest.Core/         # 无 UI 依赖：模型、SQLite、搜索索引、整理引擎、备份、日志
│   ├── DeskNest.Native/       # Win32 互操作：桌面层、拖放、Shell 图标、热键、托盘、DWM
│   └── DeskNest.ThumbProvider/# 独立进程：缩略图/图标抽取（隔离崩溃与卡顿）
├── tests/
│   ├── Core.Tests/            # 整理引擎、文件安全、命名冲突、回滚（最重要）
│   ├── Native.Tests/          # 桌面层、热键、自启
│   └── App.Tests/             # 关键交互（拖放、撤销、位置记忆）
├── installer/                 # Inno Setup 脚本（对齐 DeskBox/WitchDrawer 的安装体验）
└── docs/                      # 本策划书、架构说明、发布清单
```

依赖方向固定为 `App → Core`、`App → Native → Core`；**Core 不允许引用 WPF/Native**（这条是小项目后期不烂掉的关键）。

### 9.3 关键技术点（都是竞品验证过的做法）

1. **桌面层宿主（不注入 Explorer）**：把盒/组件窗口挂在桌面层（`Progman`/`WorkerW` 之下），窗口样式 `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`，配合"非激活覆盖窗"技术让点击不抢焦点；监听桌面层级变化（`DesktopLayerMonitor` 思路）以在"显示桌面"、UAC 提权、切换虚拟桌面时正确重挂。
2. **拖放**：实现 `IDropTarget`（含 `CF_HDROP` 与 `Preferred DropEffect` 解析以区分移动/复制）；**注意管理员权限下无法从资源管理器接收拖放**——安装/自启默认普通权限，只在需要时提权（对齐 WitchDrawer 的说明）。
3. **图标与缩略图**：`IShellItemImageFactory` / `SHGetImageList` 取图标，缩略图走独立进程；结果在后台线程转为可复用位图；有界缓存（默认 2000 项 / 128 MB，可在设置调整）。
4. **位置记忆**：显示器稳定 ID（`\\.\DISPLAY#…` 设备路径 + `EnumDisplayDevices` 校验）+ 锚点 + 边距 + 坐标版本号；显示器变化时按策略（钉住/跟随）重算。
5. **DPI**：Per-Monitor V2 感知；多 DPI 图片资源（学小智桌面的 `@125/@150/@175/@200`）；跨屏拖动时重算图标与文字尺寸。
6. **文件安全**（最高优先级）：所有目标路径规范化并校验在托管根目录内；移动同卷用 rename、跨卷 copy+delete 并校验大小/哈希；删除=还原，还原失败逐项报告且**不删除记录**；重名 `name (1).ext`；每次移动写"意图记录"，崩溃后可续做或回滚。
7. **整理引擎**：规则编译为谓词 + 动作队列；先"模拟运行"产出计划，再执行计划（**计划/执行分离**才能做到预览与一键回滚）；整理历史记录完整移动清单。
8. **搜索索引**：默认只索引（a）收纳盒内容（b）开始菜单应用（c）用户指定目录；用 SQLite FTS5 或内存前缀索引；**不做全盘扫描**（省电、免杀软误报）。可选检测 Everything 并桥接（对齐 DeskBox）。
9. **组件的崩溃隔离**：每个桌面组件在同一进程但独立 `DispatcherObject` 域 + 全局异常兜底；缩略图抽取另起进程。异常时只移除该组件并提示"组件已重新加载"，不影响主进程与桌面盒。
10. **性能与资源看门狗**（照搬 DeskBox 的实测默认值）：隐藏后 30 s 清"可重建缓存"；可见空闲 600 s 修剪工作集；瞬态窗口 600 s 释放；三级性能模式只影响动画帧率、缓存上限与缩略图质量，**不影响整理正确性**。
11. **热键**：`RegisterHotKey` + 看门狗周期心跳（被抢占后自动重注册并记日志）。
12. **更新**：独立更新器 + SHA-256 校验 + 失败回滚 + "更新前备份数据"。
13. **安装与迁移**：Inno Setup 安装包 + 安装清单文件（清单用于完整性自检与增量更新）；数据目录可迁移（迁移完成后原目录保留为备份）；提供便携模式（数据目录 = 程序目录）。

### 9.4 性能预算（验收门，逐条实测留档）

| 指标 | 目标 | 实测方式 |
| --- | --- | --- |
| 空闲 CPU | < 1%（组件+桌宠全开、无输入） | 内置性能面板记录 24 小时曲线 |
| 常驻内存 | < 150 MB（6 组件 + 12 盒 + 1 桌宠） | 同上 |

## 11. 风险与合规

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| **文件操作出错（丢失/错位）** | 用户信任崩塌，比任何功能都严重 | 计划/执行分离 + 意图记录 + 完整移动清单 + 一键回滚 + Core 层大量单元测试（这是测试投入最大的模块） |
| **与第三方 Shell 扩展/Hook 冲突** | 桌面异常、卡顿 | 学小智桌面：内置"已知冲突清单"检测 + 主动降级提示 + 一键禁用自身桌面层；**不注入 Explorer** |
| **杀软误报**（桌面层窗口 + 全局钩子） | 无法安装/被拦截 | 不做键盘钩子的默认开启、不做进程注入、签名代码（可选）、提供"关闭键盘联动"的显式开关 |
| **Windows 更新导致 API 行为变化** | 桌面层挂载失效 | 桌面层逻辑集中在 `Native` 一小块，便于快速修；提供"降级为普通置顶窗口"的兜底开关 |
| **抄竞品代码/素材导致许可问题** | 法律风险 | WitchDrawer 是 PolyForm 非商业、ZenDesktop 是 GPL-3.0：**只借鉴设计思路，不复制代码与素材**；桌宠素材只用自绘/授权素材；第三方库在"关于"页列出许可 |
| **功能膨胀** | 变成小智桌面那种全家桶 | 第 3.5 节的"不做清单"是硬约束；新功能必须先进 P2 并在版本评审时确认 |
| **用户数据隐私** | 桌面文件名/键击敏感 | 全部本地处理、默认不联网、不上传任何信息；键盘联动默认关、不记录内容；诊断包自动脱敏文件路径（可选手动勾选是否含路径） |
