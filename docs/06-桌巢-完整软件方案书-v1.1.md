## 1. 项目概述

### 1.1 一句话定位

**桌巢 DeskNest** 是 Windows 10/11 上的桌面管家：**桌面整理 + 桌面组件 + 工作伙伴桌宠**三合一，数据全部留在本机，GPL-3.0 开源。

### 1.2 目标用户

| 用户 | 场景 | 核心诉求 |
| --- | --- | --- |
| 桌面长期堆满文件的重度使用者 | 十几类文件散在桌面，找东西靠记忆 | 分区收纳盒 + 全盘搜索 + 一键整理 |
| 上班族 / 学生 | 桌面小、不想天天手动归位 | 自动整理 + 可撤销 |
| 内容创作者 / 主播 | 想要好看又能干活的桌面 | 组件 + 桌宠 + 主题 + 一键隐藏 |
| 系统美化玩家 | 喜欢 Mica/亚克力那类质感 | 材质、圆角、两组样式（全局/单独） |

### 1.3 差异化（和四个竞品比）

1. **三块能力在同一套壳里**：收纳整理 + 桌面组件 + 桌宠，其余竞品最多占两块；桌宠只有我们做，而且是"工作伙伴型"（待办提醒/番茄钟/久坐提醒/系统状态联动）。
2. **零打扰商业模式**：不弹广告、不做推广位、不注册系统右键菜单、不注入其它进程、不上传数据、基础功能不做付费墙。
3. **一切可撤销 + 一切可关闭**：整理有完整移动清单可回滚；每个模块、每个动效、每个热键都能单独关。
4. **两级样式**：全局样式 + 单个盒子/组件覆盖，既能一键统一也能各自独立。

### 1.4 永久红线（写进代码与文档）

不弹广告 / 不做推广位 / 不注册任何 Shell 右键菜单 / 不注入其它进程 / 不静默上传数据 / 基础功能不做付费墙。

## 2. 竞品与美术资源研究

> 证据等级：**A** = 本机实测（装着的软件、安装包、配置、日志）；**B** = 上游源码/官方文档；**C** = 公开资料未验证。所有分析均为**只读**；360 桌面只下载安装包剥壳、**从未安装运行**。

### 2.1 DeskBox 1.5.7（A 级 + B 级源码，**已确认开源**）

**是什么**：`github.com/Tianyu199509/DeskBox`，**6,944★ / 365 fork / C# / GPL-3.0**，默认分支 `main`，主页 `deskbox.fun`。本机安装版 1.5.7 就在调用 `api.github.com/repos/Tianyu199509/DeskBox/releases/latest` 检查更新——与安装包署名"朱天雨"（Tianyu）一致。

**UI 是怎么搭的**（B 级，源码级证据）：

| 方面 | 具体做法 |

| 框架 | **WinUI 3 / Windows App SDK**（原生 Fluent Design：Mica 背景、系统圆角、`ToggleSwitch`/`SettingsCard` 等原生控件） |
| 资源字典 | `src/DeskBox/App.xaml` 34 KB，**112 个资源键 × 多套主题字典**，在 Fluent 之上叠了自己的中性色令牌：`DeskBoxNeutralFill/FillSecondary/FillTertiary/Line/TextPrimary`、`WidgetOverlaySurface/Input/Stroke`、`WidgetDragHandle`、`WidgetCornerRadiusSmall/Medium/Large`、`DeskBoxMenuFontFamily/FontSize` |
| 设置页样式 | `src/DeskBox/Styles/SettingsOverviewResources.xaml`：**行最小高 64、行内边距 16/10、图标与文字间距 20、卡片圆角 6、卡片间距 4、页面标题 28 SemiBold、设置项标题 14、说明 12（次要色）、子标题 15 SemiBold；按钮 34 高 / 最小宽 104 / 内边距 12 / 圆角 6；图标按钮 30×30 圆角 5；色板按钮 26 圆形** |

| 本地化 | `Resources/<locale>/Resources.resw` **12 种语言**，设置页可切换 |

### 2.3 360 桌面精简版 11.0.0.2281（A 级，只剥壳未安装）

安装器 `360DesktopLite_Setup.exe`（PE 壳 + 内嵌 CAB + 内嵌 7z，58 个文件 / 44.5 MB）。UI 同样走 **DuiLib**：`Themes/default/360desktoplite.ui`（3.9 MB）、`theme.xml`、`defaultskin.ui`、`MiniUI.xml`、**带皮肤的卸载器 `Uninstall.uiz`**；素材含 `eye.swf`、`bell.wav`；另带 `FolderPromotion.exe`（推广）与 `360DeskAna.exe`（统计上报）。

**学**：它对自动化很克制（`arrange close_count=3 day_time_interval=7`：整理被连关 3 次就停一天）。**避**：推广模块、统计上报、注册 DeskBand 到资源管理器。

### 2.4 WitchDrawer 1.4.4 与 ZenDesktop 4.1.0（B 级，源码）

- **WitchDrawer**：.NET 10 + **WPF**，界面**完全由 XAML 样式表**构成，几乎不用位图素材（只有 `app.ico`/`app.png`），字符串走 `Strings.resx` + `Strings.zh-CN.resx` 双语言。→ 证明"纯 XAML 也能做出干净观感"，正是我们走的路。许可 **PolyForm Noncommercial**，只能学思路。
- **ZenDesktop**：自身没有界面，靠 **Windhawk 注入**改系统控件 + ExplorerBlurMica 提供毛玻璃。→ 我们把"亚克力/毛玻璃"归给**系统合成器**（DWM），不注入。

## 4. 信息架构与数据模型

### 4.1 界面结构（当前实现）

```
主窗口（左栏 232px 导航 + 顶部搜索 + 内容列最大 840px）
  ├ 通用：概览 / 收纳盒 / 整理与规则 / 桌面组件
  ├ 外观：外观与主题
  ├ 功能：模块 / 桌宠 / 性能监视 / 使用统计 / API 面板 / 计划关机 / AI 接口
  └ 维护：数据与备份 / 关于

桌面层（不抢焦点、贴桌面 WorkerW 之下）
  ├ 收纳盒窗口 × N（可编组）
  ├ 组件窗口 × N
  └ 桌宠窗口

独立窗口：快捷搜索面板（Alt+Space）、托盘菜单、通知气泡
```

### 4.2 数据模型（SQLite：`%LOCALAPPDATA%\DeskNest\desknest.db`）

`boxes`（含形态/存储模式/锚点/位置/尺寸/样式覆盖）、`items`（原路径/存储路径/加入时间/失效标记）、`box_groups`、`widgets`、`todos`、`notes`、`rules`、`org_runs`（整理历史 + 完整移动清单）、`pets`、`usage_sessions`、`power_plan`、`api_providers`/`api_stats`、`journal`（文件操作意图记录）、`search_index`（索引缓存）。

配套：`settings.json`（+`.bak` 双写）、`logs\desknest.log`（4 MB 轮转）、`backups\*.zip`、`pets\<id>\`。

### 5.4 用本地 ComfyUI 生成素材的工作流

1. 用绘世启动器启动 ComfyUI（默认 `127.0.0.1:8188`）；

## 6. 技术架构

### 6.1 分层

```
DeskNest.App（WPF 界面）
  ├ 主窗口（行式设置页）/ 桌面盒 / 组件 / 桌宠 / 搜索面板 / 托盘
  └ Ui：设计令牌、控件样式、图标系统、组件库、应用图标
DeskNest.Core（无 UI 依赖，可单测）
  ├ Models + Repository + Db（SQLite/WAL）
  ├ FileOps / OrganizeEngine / RulesEngine（文件安全与整理）
  ├ SearchService（索引 + 持久化）
  ├ ApiPanelService / AiBridgeService / UsageStatsService / PerfSampler / PowerScheduler
  └ BackupService / PetEngine / PetPack / ComfyUiClient（本地素材工具，模块化）
DeskNest.Native（Win32 互操作）
  ├ DesktopLayer（挂 WorkerW）/ DesktopIcons / ShellIcons / DwmEffects
  ├ GlobalHotKey / KeyboardHook（只暴露"有按键"事实）/ ForegroundWatcher
  └ SystemMetrics / PowerActions / DpapiSecretBox / AutoStart / Monitors / MediaKeys
DeskNest.Module.*（可选模块，独立 dll）
```

依赖方向固定：`App → Core`、`App → Native → Core`；Core 不引用 WPF/WinForms。

### 6.2 关键技术决策

| 决策 | 理由 |
| --- | --- |
| .NET 10 + WPF | 桌面层窗口、拖放、Shell 集成成熟；WitchDrawer 已验证可行；自包含发布免装运行时 |
| 不注入 Explorer | 注入方案随系统更新易失效且有杀软风险；我们用自己的桌面层窗口，卸载即干净 |
| 计划/执行分离 + 意图记录 | 整理可预览、可回滚；崩溃后可审计 |
| 索引持久化 | 全盘 326 万条若每次重扫不可接受；落盘后启动即可用 |
| 模块独立 dll | 未安装＝零占用、界面不出现，满足"每个模块都能决定开不开" |
| API Key 用 DPAPI 加密 | 不落明文，且不依赖自研加密 |
| 图标用矢量而非位图 | 多尺寸清晰、可按主题改色、体积小；来源于 MIT 上游 |

### 6.3 性能预算（验收门）

空闲 CPU < 1%；常驻内存 < 150 MB；热键到面板 < 200 ms；**UI 线程不做磁盘 IO / 数据库写 / 图标提取**；列表虚拟化开启；隐藏后清理可重建缓存（默认 30 秒）。

## 10. 风险与合规
